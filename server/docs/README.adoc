= Lowcode REST API documentation

OpenAPI 3 definitions in this directory are generated from `server/{system,compose,automation,federation,discovery}/rest.yaml`.

== Regenerate

[source,shell]
----
make docs
----

The command runs `docs/convert.py` and rewrites `*.yaml`, then `docs/pack.py`.

`pack.py` copies the user manual (`manual/ru/tools/docserver/html`) and renders architecture pages from `docs/*.md` into this package. `go:embed` in `serve.go` puts all three into the server binary:

* `/api/docs/` — this directory's OpenAPI files and `index.html`
* `/api/manual/` — user manual
* `/api/architecture/` — architecture pages

When web applications are disabled and the API stays on `/`, the same trees are served at `/docs/`, `/manual/` and `/architecture/`.

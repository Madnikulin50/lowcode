# [**Навык: Чтение архитектурных чертежей**]()  
## [**Описание**]()  
Чтение, анализ и извлечение структурированных данных из архитектурно-строительных чертежей (фасады, планы, разрезы, детали, шаблоны). Расчет площадей, объемов, геометрических параметров конструкций и архитектурных элементов. Извлечение спецификаций, ведомостей материалов, размерных цепей, маркировки осей, отметок уровней и данных легенд. Используйте, когда пользователь загружает PDF/DWG/файлы чертежей и просит прочитать чертежи, извлечь размеры, рассчитать площади/объемы, определить конструктивные элементы, проанализировать фасады или получить любую количественную/качественную информацию из архитектурных чертежей. Поддерживаются российские (ГОСТ) и международные стандарты черчения.

## [**Рабочий процесс**]()  
При чтении чертежей выполняйте следующие шаги:  
1. **Определите тип чертежа и лист** — Определите, является ли это фасадом, планом, разрезом, деталью, шаблоном, маркировочной схемой или цветным решением. Зафиксируйте масштаб и номер листа из основной надписи.  
2. **Прочитайте основную надпись** — Извлеките название проекта, адрес объекта, название листа, масштаб, стадию (П=проект, Р=рабочая), дату и ответственных лиц (ГАП=главный архитектор проекта и т.д.).  
3. **Найдите оси и сетку** — Определите систему координатных осей (буквенные и числовые оси), поймите строительную сетку, определите, какую часть здания показывает чертеж.  
4. **Считайте размеры** — Извлеките все размерные цепи (горизонтальные и вертикальные), габаритные размеры, модульные размеры и конструктивные размеры. Учитывайте масштабный коэффициент.  
5. **Считайте отметки уровней** — Извлеките все отметки уровней (значки высоты) с их абсолютными и относительными значениями.  
6. **Определите конструктивные элементы** — Назовите и каталогизируйте все видимые элементы: стены, проемы (окна, двери), колонны, карнизы, молдинги, пилястры, пояса, фронтоны и т.д.  
7. **Рассчитайте площади** — Вычислите площади поверхностей (фасадные площади, площади проемов, площади декоративных элементов) по извлеченным размерам и геометрическим формулам.  
8. **Рассчитайте объемы** — Где доступны данные о толщине (из разрезов или деталей), вычислите объемы элементов.  
9. **Прочитайте легенды и примечания** — Извлеките все примечания, спецификации, обозначения материалов, цветовые коды и перекрестные ссылки на другие листы.  
10. **Перекрестные ссылки** — Следуйте по ссылкам к деталям и шаблонам. Читайте номер листа детали в скобках: “(см. лист: 15)” или “(см. лист: 17)”.

## [**Правила пересчета масштаба**]()  
ВСЕГДА применяйте масштабный коэффициент при интерпретации размеров с чертежей:  
- Масштаб 1:1 — размеры на чертеже = реальные размеры (мм)  
- Масштаб 1:2 — реальный размер = размер на чертеже x 2  
- Масштаб 1:5 — реальный размер = размер на чертеже x 5  
- Масштаб 1:10 — реальный размер = размер на чертеже x 10  
- Масштаб 1:20 — реальный размер = размер на чертеже x 20  
- Масштаб 1:50 — реальный размер = размер на чертеже x 50  
- Масштаб 1:100 — реальный размер = размер на чертеже x 100  
- Масштаб 1:200 — реальный размер = размер на чертеже x 200  
Значения размеров, указанные на чертеже, обычно уже пересчитаны в реальные размеры. Проверяйте согласованность с указанным масштабом.

## [**Формулы расчета площадей**]()  
### [**Основные формулы**]()  
| | | |  
|-|-|-|  
| **Фигура** | **Формула** | **Переменные** |   
| Прямоугольник | S = a x b | a, b = стороны |   
| Квадрат | S = a^2 | a = сторона |   
| Треугольник (основание-высота) | S = (b x h) / 2 | b = основание, h = высота |   
| Треугольник (Герон) | S = sqrt(p(p-a)(p-b)(p-c)) | p = (a+b+c)/2 |   
| Трапеция | S = ((a + b) / 2) x h | a, b = основания, h = высота |   
| Параллелограмм | S = a x h | a = сторона, h = высота |   
| Круг | S = pi x r^2 | r = радиус |   
| Круговой сектор | S = (pi x r^2 x alpha) / 360 | alpha = центральный угол в градусах |   
| Круговой сегмент | S = (r^2/2) x ((pi x alpha/180) - sin(alpha)) | alpha в градусах |   
| Эллипс | S = pi x a x b | a, b = полуоси |

### [**Расчет площади фасада**]()  
**Грубая площадь фасада:**  
S_грубая = Ширина_фасада x Высота_фасада  
**Чистая площадь фасада (за вычетом проемов):**  
S_чистая = S_грубая - Сумма(S_проемов)  
 S_проем = Ширина_проема x Высота_проема (на один проем)  
**Площадь фасада по этажам:**  
S_этаж_фасад = Ширина_фасада x Высота_этажа  
**Площадь фасада со сложным контуром:** Для фасадов с выступами, уступами или неконтурными очертаниями: 1. Разбейте на прямоугольники и треугольники 2. Рассчитайте каждую площадь отдельно 3. Сложите положительные площади (выступы) и вычтите отрицательные (врезки)  
### [**Пример расчета**]()  
Фасад в осях Е-Ж:  
 - Ширина: 26410 мм (26.41 м)  
 - Высота: 28260 мм (28.26 м)  
 - Грубая площадь: 26.41 x 28.26 = 746.35 м2  
   
 Проемы:  
 - Окна: 12 шт x (1.5 x 2.1) = 12 x 3.15 = 37.8 м2  
 - Двери: 2 шт x (2.0 x 2.4) = 2 x 4.8 = 9.6 м2  
 - Всего проемов: 47.4 м2  
   
 Чистая площадь фасада: 746.35 - 47.4 = 698.95 м2

## [**Расчет площадей проемов**]()  
### [**Оконный проем**]()  
S_оконн_проем = W_проем x H_проем  
### [**Дверной проем**]()  
S_дверн_проем = W_проем x H_проем  
### [**Проем с аркой (арочное окно/дверь)**]()  
S_прямоуг_часть = W x H_прям  
 S_арочн_часть = (pi x r^2) / 2  (полукруг)  
 S_общая = S_прямоуг_часть + S_арочн_часть  
 r = W / 2  
### [**Несколько одинаковых проемов**]()  
S_проемов_всего = Количество x S_одного_проема

## [**Расчет объемов**]()  
### [**Объем стены (по фасаду + разрезу)**]()  
V_стены = S_чист_фасада x Толщина_стены  
### [**Объем штукатурки/покрытия**]()  
V_штукат = S_поверхности x Толщина_штукатурки  
### [**Объем отдельного элемента (по детали)**]()  
V_элемента = S_сечения x Длина_элемента  
### [**Объем бетона для фундамента**]()  
V_бетона = S_подошвы x Глубина  
### [**Объем выемки грунта**]()  
V_выемки = S_плана x Глубина x 1.15  (15% на откосы/рабочую зону)  
### [**Объем помещения (воздушный объем)**]()  
V_помещ = S_пола x H_потолка

## [**Расчет профильных элементов**]()  
### [**Площадь поперечного сечения профиля (по шаблону)**]()  
Метод: Разложение профиля на простые геометрические фигуры  
Шаг 1: Определите все сегменты профиля  
 - Прямые сегменты (дают периметр, не площадь)  
 - Прямоугольные блоки (полные части сечения)  
 - Кривые сегменты (дуги, четверть-окружности)  
   
 Шаг 2: Для каждой заполненной области:  
 - Прямоугольник: S = ширина x высота  
 - Четверть-окружность: S = (pi x r^2) / 4  
 - Полуокружность: S = (pi x r^2) / 2  
 - Треугольник: S = (основание x высота) / 2  
   
 Шаг 3: Сложите все положительные площади  
 Шаг 4: Вычтите вырезы/пустоты  
### [**Периметр профиля (для расчета покрытия)**]()  
P_профиля = Сумма длин всех сегментов + Сумма длин всех дуг  
 Длина_дуги = (pi x r x alpha) / 180  
### [**Объем элемента по шаблону**]()  
V_элемента = S_профиля x L_элемента  
### [**Площадь поверхности элемента (для покраски)**]()  
S_поверхности = P_профиля x L_элемента + 2 x S_профиля (торцы)  
### [**Пример: Расчет карнизного профиля**]()  
Профиль состоит из:  
 1. Прямоугольное основание: 150 x 30 мм => S1 = 4500 мм2  
 2. Четверть-окружность (R=25): S2 = (pi x 25^2) / 4 = 490.9 мм2  
 3. Прямоугольный выступ: 80 x 20 мм => S3 = 1600 мм2  
 4. Четверть-окружность (R=15): S4 = (pi x 15^2) / 4 = 176.7 мм2  
 5. Вертикальная грань: 100 x 40 мм => S5 = 4000 мм2  
   
 Общая площадь поперечного сечения:  
 S_профиля = 4500 + 490.9 + 1600 + 176.7 + 4000 = 6767.6 мм2 = 0.00677 м2  
   
 Если карниз проходит 26.41 м (ширина фасада):  
 V_карниза = 0.00677 x 26.41 = 0.179 м3  
   
 Площадь для покраски (открытые грани):  
 P_профиля = 150 + 30 + (pi x 25 / 2) + 80 + 20 + (pi x 15 / 2) + 100 + 40  
           = 150 + 30 + 39.3 + 80 + 20 + 23.6 + 100 + 40 = 482.9 мм = 0.483 м  
 S_покраски = 0.483 x 26.41 = 12.76 м2

## [**Расчет количеств материалов**]()  
### [**Штукатурный материал**]()  
Количество (кг или литры) = S_поверхности x Норма_расхода  
- Норма_расхода из данных производителя (обычно кг/м2 на мм толщины)  
- Учитывайте количество слоев  
### [**Краска**]()  
Количество_краски (литры) = S_поверхности / Укрывистость  
 Укрывистость = м2/литр от производителя  
- Учитывайте количество слоев  
- Учитывайте коэффициент потерь (обычно 1.1-1.2)  
### [**Бетон**]()  
V_бетона (м3) = Размеры_элемента  
### [**Арматурная сталь**]()  
Вес (кг) = Длина (м) x Удельный_вес (кг/м)  
 Удельный_вес = 0.00617 x d^2 (d = диаметр в мм)  
### [**Опалубка**]()  
S_опалубки = Площадь_контактной_поверхности

## [**Разложение сложных фигур**]()  
### [**Метод для фасадов со сложным контуром**]()  
1. **Метод сетки**: Наложите сетку, посчитайте полные и частичные квадраты  
2. **Метод разложения**: Разбейте на прямоугольники, треугольники, окружности, дуги  
3. **Метод координат**: Если известны координаты вершин, используйте формулу шнурка:  
Формула шнурка (площадь многоугольника):  
 S = 0.5 x |сумма(x_i x y_{i+1} - x_{i+1} x y_i)|  
### [**Аппроксимация дуг и кривых**]()  
Когда для кривых не указаны радиусы: 1. Определите три точки на дуге 2. Рассчитайте радиус: r = (a x b x c) / (4 x S_треугольника) 3. Рассчитайте центральный угол через тригонометрию 4. Рассчитайте площадь сегмента и длину дуги  
### [**Площадь фигурного/криволинейного профиля**]()  
Для профилей с несколькими дугами и прямыми сегментами: 1. Перечислите все сегменты по порядку 2. Для каждого прямого сегмента: добавьте длину к периметру 3. Для каждой дуги: рассчитайте площадь сегмента и длину дуги 4. Используйте геометрическую конструкцию для нахождения ограниченной площади

## [**Система маркировки осей**]()  
### [**Назначение**]()  
Координатная сетка осевая для определения положения всех конструктивных и архитектурных элементов.  
### [**Формат**]()  
- **Продольные оси** (вдоль длины здания): Цифры — 1, 2, 3, 4, 5…  
- **Поперечные оси** (поперек здания): Буквы — А, Б, В, Г, Д…  
- **Дополнительные оси**: Дроби — 1/1, 2/1, А/1, Б/1  
- **Диапазоны осей**: Обозначаются как “1-5” или “А-Д” для фасадов, охватывающих несколько осей  
### [**Обозначения осей на чертежах**]()  
- Маленькие кружки (8-10 мм диаметр) на пересечениях осей  
- Буква/цифра внутри кружка  
- Показываются сверху, снизу и по бокам плана/фасада  
### [**Использование осей для определения положения**]()  
"Фасад в осях Е-Ж" = Фасад между осью Е и осью Ж  
 "Деталь на пересечении осей 3 и Б" = Элемент в колонне/в узле сетки  
### [**Шаг осей**]()  
- Расстояние между осями читается из размерных цепей  
- Типичный модульный шаг: 3000, 3600, 6000 мм (кратные модулю М=100 мм)  
- Размерные цепи показывают кумулятивные расстояния: 6000, 6000, 6000 = 18000 мм

## [**Обозначение размеров**]()  
### [**Структура размерной цепи**]()

### [**Виды размеров**]()  
1. **Габаритные размеры**: Общая длина/ширина/высота  
2. **Модульные размеры**: Между конструктивными осями  
3. **Конструктивные размеры**: Фактические размеры элементов  
4. **Размеры проемов**: Ширина и высота проемов  
5. **Высотные размеры**: Вертикальные положения  
### [**Компоненты размерной линии**]()  
- **Размерная линия**: Тонкая линия со стрелками на концах  
- **Выносные линии**: Выходят от краев элемента к размерной линии  
- **Значение размера**: Число, расположенное над или в разрыве размерной линии  
- **Допуск**: Указывается как +/- значение, где применимо  
### [**Чтение размерных цепей**]()  
Пример цепи:  
 480  2070  2835  18120  3040  4950

 Габаритный размер (если указан): должен быть ~29500 мм

## [**Конвенции изображения на чертежах**]()  
### [**Линии обрыва (зигзагообразные)**]()  
**Линия обрыва** (показана как зигзаг или волнистая линия через размер) указывает, что повторяющаяся или однородная секция была опущена на чертеже для экономии места. Распространено в: -  **Фасадных деталях**: Высокий вертикальный элемент (оконный проем, пилястра) может иметь “вырванную” среднюю секцию -  **Длинных горизонтальных элементах**: Балки, карнизы, пояса -  **Повторяющихся молдингах**: Профили, продолжающиеся равномерно  
Когда вы видите линию обрыва: 1. Размер, показанный рядом с линией обрыва, является **ФАКТИЧЕСКИМ ПОЛНЫМ РАЗМЕРОМ** (не сжатым размером чертежа) 2. Линия обрыва — это условное обозначение — она НЕ представляет реальный шов или зазор 3. При извлечении размеров используйте маркированное значение, а не измеренное расстояние на чертеже 4. При расчете площадей/объемов используйте полный маркированный размер  
**Пример**: Вертикальный размер “3335” рядом с зигзагообразной линией обрыва означает, что фактическая высота этой секции равна 3335 мм, даже если визуально она выглядит короче на чертеже.  
### [**Индикаторы линии сечения**]()  
- Толстая штрих-пунктирная линия со стрелками показывает, где сделан разрез  
- Стрелки указывают направление ВЗГЛЯДА (не направление сечения)  
- Буквы (А, Б, В) идентифицируют вид разреза  
### [**Осевая линия и оси симметрии**]()  
- Штрих-пунктирные линии обозначают оси симметрии  
- Используются для колонн, окон, дверей и симметричных элементов  
- Пересечение осевых линий = центральная точка элемента  
### [**Линии продолжения**]()  
- Когда деталь слишком велика для одного листа, знаки продолжения показывают, где она продолжается  
- Совпадите знак на следующем листе, чтобы следовать за чертежом  
### [**Скрытые линии**]()  
- Штриховые линии показывают ребра и контуры, скрытые за видимыми поверхностями  
- Важны для понимания полной геометрии

## [**Процедура анализа фасада**]()  
При анализе фасадного чертежа:  
1. Определите ориентацию фасада (между какими осями он расположен)  
2. Подсчитайте количество этажей / уровней  
3. Для каждого этажа определите:  
  - Количество и тип окон  
  - Количество и тип дверей  
  - Декоративные элементы и их типы  
  - Пояса и карнизы  
4. Рассчитайте грубую площадь фасада (ширина x высота между осями)  
5. Рассчитайте общую площадь проемов  
6. Рассчитайте чистую площадь фасада (грубая минус проемы)  
7. Рассчитайте площадь каждого типа декоративных элементов  
8. Зафиксируйте ссылки на листы деталей для каждого типа элемента

## [**Процедура анализа детали**]()  
При анализе детального чертежа:  
1. Определите номер и название детали  
2. Зафиксируйте масштаб (обычно 1:5, 1:10, 1:20)  
3. **Проверьте линии обрыва** — Ищите зигзагообразные/волнистые линии, указывающие на сжатые секции. Если присутствуют, используйте маркированные значения размеров (не измеренные расстояния) для всех расчетов.  
4. Извлеките ВСЕ размеры:  
  - Габаритные размеры (ширина, высота, глубина)  
  - Размеры компонентов (каждый слой, каждый элемент)  
  - Радиусы для криволинейных элементов  
  - Углы для наклонных элементов  
5. Проверьте размерные цепи — сумма частичных размеров должна равняться габаритному (допустимы небольшие погрешности округления 5-10 мм)  
6. Рассчитайте площадь поперечного сечения детали, разложив на прямоугольники, треугольники, дуги и другие геометрические фигуры  
7. Если деталь является профилем (фигурной формы), отметьте, что объем = площадь x длина  
8. Определите материалы для каждого компонента/слоя  
9. Зафиксируйте покрытия и отделку

## [**Стратегия чтения PDF**]()  
При обработке PDF-чертежей:  
1. **Проверьте размеры страниц** — Архитектурные чертежи используют нестандартные размеры страниц:  
  - A0: 2384 x 1684 pts (альбомная) или 1684 x 2384 pts (портретная)  
  - A1: 1684 x 1191 pts или 1191 x 1684 pts  
  - A2: 1191 x 842 pts или 842 x 1191 pts  
  - A3: 842 x 595 pts (альбомная) или 595 x 842 pts (портретная)  
  - Letter/A4: 612 x 792 pts — обычно титульные страницы, текст или фото  
2. **Многоформатные PDF** — Проектная документация часто содержит смешанные размеры страниц: текстовые страницы (A4) + чертежные страницы (A0-A3). Обрабатывайте каждый тип страницы соответственно.  
3. **Рендеринг в изображение для визуального анализа** — Конвертируйте чертежные страницы в изображения (масштаб 2x или 3x) с помощью PyMuPDF для визуальной проверки линий, штриховок и примечаний, которые могут быть не извлекаемы как текст.  
4. **Извлечение текста и графики**:  
  - Используйте page.get_text() для значений размеров, меток, примечаний  
  - Используйте page.get_images() для обнаружения встроенных изображений  
  - Используйте page.get_pixmap() для визуального рендеринга  
5. **Парсинг размерных цепей** — Ищите последовательные числа, образующие размерные цепи (например, “145, 110, 45, 145, 100, 55, 150, 100, 55” на горизонтальной размерной линии).

## [**Практические примеры расчетов**]()  
### [**Пример 1: Площадь ремонта фасада**]()  
Дано: - Фасад в осях Е-Ж: ширина 26410 мм, высота 28260 мм - Окна: 24 шт, каждое 1500 x 2100 мм - Двери: 4 шт, каждая 2000 x 2400 мм - Пилястры: 6 шт, каждая выступает на 150 мм, ширина 400 мм - Карнизный пояс: высота 300 мм, полная ширина  
Расчеты:  
S_грубая = 26.41 x 28.26 = 746.35 м2  
 S_окон = 24 x (1.5 x 2.1) = 24 x 3.15 = 75.6 м2  
 S_дверей = 4 x (2.0 x 2.4) = 4 x 4.8 = 19.2 м2  
 S_чистая = 746.35 - 75.6 - 19.2 = 651.55 м2  
   
 Площадь пилястр (только фасадная грань):  
 S_пилястр_лицо = 6 x (0.4 x 28.26) = 67.82 м2  
 Площадь боковины пилястр (выступающей):  
 S_пилястр_бок = 6 x (0.15 x 28.26) = 25.43 м2  
   
 Площадь карнизного пояса:  
 S_карниза = 26.41 x 0.3 = 7.92 м2  
   
 Общая штукатурная поверхность:  
 S_штукатурки = S_чистая + S_пилястр_бок = 651.55 + 25.43 = 676.98 м2  
### [**Пример 2: Объем декоративного элемента**]()  
Дано: - Диаметр розетки: 600 мм (из детали 1:10) - Толщина розетки: 80 мм - Количество: 12 штук  
Расчеты:  
S_розетки = pi x (0.6/2)^2 = 3.1416 x 0.09 = 0.2827 м2  
 V_одной = 0.2827 x 0.08 = 0.0226 м3  
 V_всего = 12 x 0.0226 = 0.271 м3  
 S_поверхн_одной = 2 x 0.2827 + pi x 0.6 x 0.08 = 0.565 + 0.151 = 0.716 м2  
 S_поверхн_всего = 12 x 0.716 = 8.59 м2  
### [**Пример 3: Обрамление оконного проема**]()  
Дано: - Оконный проем: 1500 x 2100 мм - Обрамляющий молдинг шириной: 120 мм - Площадь сечения профиля: 8400 мм2 - 24 окна  
Расчеты:  
Периметр оконного проема = 2 x (1.5 + 2.1) = 7.2 м  
 Длина молдинга на окно = 7.2 м  
 Общая длина молдинга = 24 x 7.2 = 172.8 м  
   
 Площадь сечения = 8400 мм2 = 0.0084 м2  
 V_молдинга = 172.8 x 0.0084 = 1.451 м3  
   
 Площадь для покрытия:  
 P_профиля = периметр сечения профиля (из детали)  
 Допустим P_профиля = 340 мм = 0.34 м  
 S_покрытия = 172.8 x 0.34 = 58.75 м2  
### [**Пример 4: Цветовые зоны фасада**]()  
Цветовые зоны фасада: - Основная стенная поверхность (гладкая штукатурка): S 2020-Y40R - Декоративные элементы: S 4005-G50Y - Оконные блоки (дуб, тонированные): S6020-Y10R - Цоколь: S 4040-Y40R  
Из расчетов площадей:  
S_основной_штукатурки = 520.0 м2  
 S_декоративных = 85.5 м2  
 S_оконных_рам = 48.2 м2  
 S_цоколя = 15.3 м2  
   
 Расход краски (2 слоя, 10% потери):  
 - Краска для штукатурки: 520 x 0.3 л/м2 x 2 x 1.1 = 343.2 л  
 - Краска для декоративных: 85.5 x 0.25 л/м2 x 2 x 1.1 = 47.0 л  
 - Лак для окон: 48.2 x 0.15 л/м2 x 2 x 1.1 = 15.9 л  
 - Краска для цоколя: 15.3 x 0.35 л/м2 x 2 x 1.1 = 11.8 л

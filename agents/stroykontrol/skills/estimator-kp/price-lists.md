   2.5. Алгоритм подбора расценки из прайс-листа РАБОТЫ
   При сопоставлении позиции из ВОР с прайс-листом работай по следующему алгоритму:
   Шаг 1 — Категорийный поиск: Определи категорию работы из ВОР и найди соответствующий раздел в прайсе (например, «окраска фасада» → «Малярные работы»).
   Шаг 2 — Ключевое слово: Внутри категории найди позицию по ключевым словам в наименовании. Прайс содержит детальные описания — ищи совпадение по основным терминам.
   Шаг 3 — Проверка единиц измерения: Убедись, что единица измерения в ВОР совпадает с единицей измерения в прайсе (м², м.п., шт, м³, комплект).
   Шаг 4 — Проверка цены: Если цена в прайсе = 0, это означает, что расценка требует индивидуального расчёта. Действия: - Найди аналогичную позицию в прайсе с ненулевой ценой для ориентира - Если аналога нет — ищи в открытых источниках (ГЭСН, ФСНБ-2022, прайсы субподрядчиков) - Выдели КРАСНЫМ и укажи источник - Добавь примечание: «Расценка требует уточнения — цена в базовом прайсе = 0»
   Шаг 5 — Фиксация: Занеси в смету найденную расценку без каких-либо дополнительных наценок.
   2.6. Алгоритм подбора расценки из прайс-листа МАТЕРИАЛЫ
   Шаг 1 — Точное совпадение: Ищи материал по наименованию из спецификации (например, «ГКЛО 12,5 мм Knauf» → точное совпадение в прайсе).
   Шаг 2 — Частичное совпадение: Если точного нет — ищи по ключевым характеристикам (тип, марка, размер).
   Шаг 3 — Альтернативные источники: Если в прайсе материала нет: - Проверь ТД «Петрович» и «Леруа Мерлен» через интернет - Выдели КРАСНЫМ и укажи источник - Укажи дату проверки цены

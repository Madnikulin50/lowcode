# Таблицы модели угроз и поверхности атаки (формат ФСТЭК)

Версия: 2026-11-14 · Ветка `2026.10.x`.
Машиночитаемый источник: [fstec-threat-model.yaml](fstec-threat-model.yaml),
[fstec-attack-surface.yaml](fstec-attack-surface.yaml).
Основа: [threat-model.md](threat-model.md), [attack-surface.md](attack-surface.md),
[SECURITY_AUDIT_FSTEC.md](../../SECURITY_AUDIT_FSTEC.md).

Документ — сводные таблицы в форме, пригодной для включения в состав
документации по защите информации (приказ ФСТЭК № 17 от 11.02.2013,
Методика оценки угроз ФСТЭК от 05.02.2021, приказ ФСТЭК № 239 от 25.12.2017).
Это **технические исходные данные разработчика**; итоговую модель угроз
утверждает оператор конкретной системы (поля «заполняется оператором»).

Обозначения: **К** — конфиденциальность, **Ц** — целостность, **Д** — доступность.
Остаточный риск: **Н** — низкий, **С** — средний, **В** — высокий.

## Приложение. Что заполняет оператор

1. Тип системы, класс защищённости/категория значимости (Таблица 1).
2. Сопоставление угроз с УБИ БДУ ФСТЭК (колонка в Таблице 4, поле `bdu` в YAML).
3. Оценку негативных последствий для собственных процессов; исключение неактуальных угроз с обоснованием.
4. Адаптацию мер профиля (Таблицы 6–7) и компенсирующие меры по рекомендациям Таблицы 4.
5. Переоценку при изменении архитектуры, агентов, версий.

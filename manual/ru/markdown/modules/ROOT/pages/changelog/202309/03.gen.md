.[#2023*09*03-added]#[2023*09*03-added,Добавлено:](#2023*09*03-added,Добавлено:)#
- Добавлена возможность экспорта полей записей.
Изменение было добавлено, чтобы пользователи могли легко экспортировать поля записей.
([`3ed3b1e`](https://github.com/lowcode/lowcode/commit/3ed3b1e)).
- Добавлены светлая и тёмная темы, а также возможность задавать пользовательские цвета для переменных темизации.
Добавлена опция установки фирменного цвета при настройке блока страницы, поля записи или метрики отчёта.
Изменение было добавлено, чтобы предоставить пользователю больше свободы в настройке LowCoooode.
([`1579`](https://github.com/lowcode/lowcode/pull/1579), [`1671`](https://github.com/lowcode/lowcode/pull/1671)).
- Добавлены отсутствующие переводы `Manage schema alterations` в разрешениях компонента System в Admin.
([`82f21b7`](https://github.com/lowcode/lowcode/commit/82f21b7)).
- Добавлены общие оптимизации в движок выполнения рабочих процессов, генерацию ID и оценку контроля доступа.
([`49e72cb`](https://github.com/lowcode/lowcode/commit/49e72cb)).

Изменение было внесено для согласованности с остальным интерфейсом LowCoooode.
([`d82c5e6`](https://github.com/lowcode/lowcode/commit/d82c5e6)).
- Изменён внешний вид сортировки во всех веб-приложениях, чтобы он соответствовал интерфейсу в Low Code.
Изменение было внесено для стандартизации внешнего вида сортировки во всех веб-приложениях.
([`1634`](https://github.com/lowcode/lowcode/pull/1634)).

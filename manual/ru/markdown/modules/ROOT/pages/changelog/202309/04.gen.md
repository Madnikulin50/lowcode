# `2023.9.4`

.[#2023*09*04-added]#[2023*09*04-added,Добавлено:](#2023*09*04-added,Добавлено:)#
- Добавлена кнопка закрытия во все запросы рабочих процессов.
Изменение было добавлено, чтобы пользователи могли отменять рабочие процессы/запросы.
([`3708ca9`](https://github.com/lowcode/lowcode/commit/3708ca9)).

.[#2023*09*04-fixed]#[2023*09*04-fixed,Исправлено:](#2023*09*04-fixed,Исправлено:)#
- Исправлена ситуация, когда выпадающий список запроса селектора записей рабочего процесса появлялся позади запроса, делая его непригодным для использования.
([`27e142c`](https://github.com/lowcode/lowcode/commit/27e142c)).
- Исправлена ситуация, когда звёздочка обязательных полей не отображалась рядом с подписью поля в блоках записи.
([`65832b4`](https://github.com/lowcode/lowcode/commit/65832b4)).
- Исправлено применение некорректного значения к полю записи даты и времени при попытке удалить уже установленное значение.
([`6fe0b8a`](https://github.com/lowcode/lowcode/commit/6fe0b8a)).
- Исправлено ненужное отображение предупреждения об устаревших данных в Low Code при редактировании и загрузке записи.
([`070e751`](https://github.com/lowcode/lowcode/commit/070e751)).
- Исправлен отказ LowCoooode запускаться при обновлении с изменениями схемы записей Low Code по умолчанию.
Исправление внесено путём разрешения регистрации изменений для схемы по умолчанию, но продолжения блокировки их применения.
([`b389d50`](https://github.com/lowcode/lowcode/commit/b389d50)).
- Исправлено предупреждающее сообщение об отсутствии подходящего макета после сохранения записи, конфликтующей с условием видимости этого макета.
В некоторых случаях пользователь не мог получить доступ ни к одному макету или перенаправлялся в список пространств имён.
([`57a307e`](https://github.com/lowcode/lowcode/commit/57a307e)).
- Исправлена ситуация, когда поля «выбор», использующие API для поиска (Пользователь, Рабочий процесс), работали неправильно.
([`01bd594`](https://github.com/lowcode/lowcode/commit/01bd594)).
- Исправлена ошибка эндпоинта списка пользователей с пустым параметром userID на PostgreSQL.
([`566ff41`](https://github.com/lowcode/lowcode/commit/566ff41)).

.[#2023*09*04-security]#[2023*09*04-security,Безопасность:](#2023*09*04-security,Безопасность:)#
- Устранены уязвимости безопасности, вызванные зависимостями во всех веб-приложениях.
Это было сделано путём обновления пакетов до более стабильных версий и удаления неиспользуемых зависимостей, вызывающих уязвимости.
([`5f890d9`](https://github.com/lowcode/lowcode/commit/5f890d9)).

# `2023.9.2`

**Дата выпуска**: `2023.12.22`

.[#2023*09*02-added]#[2023*09*02-added,Добавлено:](#2023*09*02-added,Добавлено:)#
- Добавлены опции `export`, `enable`, `disable` рабочего процесса с помощью меню действий в Workflow.
Изменение было добавлено, чтобы предоставить пользователю более простой способ взаимодействия с рабочим процессом без необходимости открывать его.
([`1583`](https://github.com/lowcode/lowcode/pull/1583)).
- Добавлена интерполяция в заголовки и описания блоков, URL блока IFrame, подписи кнопок блока автоматизации, тело блока контента и функции преобразования блока метрики.
Изменение было добавлено, чтобы пользователь мог использовать записи и другие переменные в соответствующих местах.
([`1590`](https://github.com/lowcode/lowcode/pull/1590)).

.[#2023*09*02-changed]#[2023*09*02-changed,Изменено:](#2023*09*02-changed,Изменено:)#
- Изменено сообщение об ошибке при сохранении записи с рабочим процессом, чтобы включить метаданные о проблеме.
Изменение было внесено, чтобы предоставить пользователю больше информации о проблеме и о том, как её решить.
([`1571`](https://github.com/lowcode/lowcode/pull/1571)).
- Изменены правила обнаружения дубликатов модулей по умолчанию: теперь они пусты вместо заполнения пустым ограничением.
Изменение было внесено для повышения производительности всех модулей и улучшения читаемости UX.
([`1586`](https://github.com/lowcode/lowcode/pull/1586)).

.[#2023*09*02-fixed]#[2023*09*02-fixed,Исправлено:](#2023*09*02-fixed,Исправлено:)#
- Исправлена ситуация, когда диаграммы ломались при выборе опций временной шкалы `y-axis` или `both` при установленных минимальном и/или максимальном значениях оси Y.
([`1584`](https://github.com/lowcode/lowcode/pull/1584)).
- Исправлена невозможность экспорта пространства имён, потому что оно содержит ссылки на удалённые переводы ресурсов.
([`1d54026`](https://github.com/lowcode/lowcode/commit/1d54026)).
- Исправлена ситуация, когда изменения схемы DAL генерировали некорректные идентификаторы атрибутов при попытке изменить столбец.
Исправление внесено с учётом кодека атрибута хранилища при генерации DDL-запросов.
([`3e1d7bd`](https://github.com/lowcode/lowcode/commit/3e1d7bd)).
- Исправлена ситуация, когда версии записей не сохранялись после разрешения изменений схемы DAL, затрагивающих соответствующую схему версий записей.
Исправление внесено путём корректного представления, обработки и перезагрузки всех соответствующих моделей.
([`33821dd`](https://github.com/lowcode/lowcode/commit/33821dd)).
- Исправлена ситуация, когда изменение типа кодирования хранилища поля модуля ломало модуль, не позволяя хранить или представлять какие-либо данные.
([`33821dd`](https://github.com/lowcode/lowcode/commit/33821dd)).
- Исправлена ситуация, когда фильтр детализации, связанный со списком записей, не перезаписывался при добавлении нового фильтра детализации.
([`33821dd`](https://github.com/lowcode/lowcode/commit/33821dd)).

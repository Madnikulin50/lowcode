# `2023.3.2`

**Дата выпуска**: `2023.06.08`

.[#2023*03*02-added]#[2023*03*02-added,Добавлено:](#2023*03*02-added,Добавлено:)#
- Добавлена опция прозрачного цвета в средстве выбора цвета, используемом в Admin и Reporter.
Изменение было добавлено, чтобы дать пользователям больше вариантов конфигурации при выборе цвета или цвета фона для элемента.
([`1211`](https://github.com/lowcode/lowcode/pull/1211)).
- Добавлена опция установки фильтра списка записей в качестве предустановленного фильтра для пользователя.
Фильтр можно применить с помощью выпадающего меню 'Filters'.
Изменение было добавлено, чтобы дать пользователю возможность выбирать предварительно сконфигурированный фильтр.
([`1227`](https://github.com/lowcode/lowcode/pull/1227)).
- Добавлено меню с дополнительными опциями (удалить, восстановить и разрешения) для списков ресурсов в Low Code, Admin, Reporter и Workflow.
Изменение было добавлено, чтобы пользователю не приходилось прокручивать по горизонтали для доступа ко всем опциям ресурса.
([`46f5455`](https://github.com/lowcode/lowcode/commit/46f5455)).
- Добавлена ошибка устаревших данных на случай, если такие ресурсы, как рабочие процессы, обновляются, пока другой пользователь редактирует тот же ресурс.
Изменение было добавлено, чтобы уменьшить количество ошибок конфигурации, вызванных одновременным редактированием одного ресурса несколькими людьми.
([`2529cf3`](https://github.com/lowcode/lowcode/commit/2529cf3)).
- Добавлена кнопка выбора всех записей в списке записей и выполнения действий «редактировать», «удалить», «восстановить», а также выполнения рабочих процессов.
Изменение было добавлено, чтобы предоставить пользователю более простой способ редактировать, удалять, восстанавливать записи и выполнять рабочие процессы на нескольких страницах.
([`89f621c`](https://github.com/lowcode/lowcode/commit/89f621c)).

.[#2023*03*02-changed]#[2023*03*02-changed,Изменено:](#2023*03*02-changed,Изменено:)#
- Изменены внешний вид и поведение напоминаний в Low Code, что обеспечивает более простой способ работы с ними.
Изменение было внесено для согласованности с остальным интерфейсом LowCoooode и улучшения UX.
([`1239`](https://github.com/lowcode/lowcode/pull/1239)).
- Изменён домен почты обратной связи в заголовке страницы каждого веб-приложения LowCoooode с `crusttech` на `lowcodeorg`.
([`0072a4b`](https://github.com/lowcode/lowcode/commit/0072a4b)).
- Изменены напоминания: теперь счётчик откладывания сбрасывается после редактирования и изменения того, когда напоминание должно сработать.
([`256dd59`](https://github.com/lowcode/lowcode/commit/256dd59)).
- Изменён формат отображения общего количества элементов списка записей: если N — количество записей, то новый формат — от N items к N records.
([`0fcbec0`](https://github.com/lowcode/lowcode/commit/0fcbec0)).
- Изменён параметр запроса увеличения блока, который отслеживает, какой блок увеличен (масштабирован).
Изменение было внесено, чтобы гарантировать, что любые будущие реализации кода не конфликтуют с параметром запроса увеличения блока.
([`5fde4c9`](https://github.com/lowcode/lowcode/commit/5fde4c9)).
- Изменено значение переменной `SMTP_FROM` в переменных `.env` сервера.
Раньше, если значение было задано в файле `.env`, оно не учитывалось.
Изменение было внесено, чтобы дать разработчикам возможность настраивать параметры SMTP не только из интерфейса, но и через файл `env`.
([`d2b389b`](https://github.com/lowcode/lowcode/commit/d2b389b)).
- Изменена серьёзность действий рабочего процесса и триггеров по умолчанию на `notice`, чтобы она была согласована с другими ресурсами в Admin.
Изменение было внесено, чтобы действия создания, обновления, удаления и восстановления были видны в стандартном наборе правил журнала действий.
([`31f7e14`](https://github.com/lowcode/lowcode/commit/31f7e14)).

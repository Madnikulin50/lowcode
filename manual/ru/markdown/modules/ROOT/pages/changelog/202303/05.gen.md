# `2023.3.5`

**Дата выпуска**: `2023.08.24`

.[#2023*03*05-added]#[2023*03*05-added,Добавлено:](#2023*03*05-added,Добавлено:)#
- Добавлена опция настройки того, находится ли значение поля модуля в одной строке с его подписью в блоке страницы.
Изменение было добавлено, чтобы предоставить пользователю возможность задавать положение значения поля.
([`1339`](https://github.com/lowcode/lowcode/pull/1339)).
- Добавлен поиск без учёта регистра в списке записей при использовании базы данных MySQL.
Изменение было добавлено, чтобы упростить поиск записей, возвращая результаты, похожие на критерии поиска.
([`1355`](https://github.com/lowcode/lowcode/pull/1355)).

.[#2023*03*05-changed]#[2023*03*05-changed,Изменено:](#2023*03*05-changed,Изменено:)#
- Изменена навигация по страницам: теперь загрузка предыдущих ресурсов прекращается, если мы перешли на новую страницу.
Изменение было внесено для уменьшения ненужной обработки, поскольку старые ресурсы всё равно сразу отбрасывались.
([`638ba17`](https://github.com/lowcode/lowcode/commit/638ba17)).
- Внесены общие улучшения UI/UX:
** Скорректированы стили элементов в верхней панели всех веб-приложений для улучшения интерфейса в текущих и более старых версиях браузеров.
([`db740f7`](https://github.com/lowcode/lowcode/commit/db740f7)).

.[#2023*03*05-fixed]#[2023*03*05-fixed,Исправлено:](#2023*03*05-fixed,Исправлено:)#

([`895796a`](https://github.com/lowcode/lowcode/commit/895796a)).
- Исправлена ситуация, когда подстраницы compose не показывались при настройке блока страницы «навигация».
([`1359`](https://github.com/lowcode/lowcode/pull/1359)).

([`6f6df66`](https://github.com/lowcode/lowcode/commit/6f6df66)).
- Исправлена неработающая опция детализации в блоке страницы «метрика», если подпись метрики не была указана.
([`95ae09e`](https://github.com/lowcode/lowcode/commit/95ae09e)).
- Исправлена проблема утечки памяти в Low Code при переключении между разными страницами.
([`95cf245`](https://github.com/lowcode/lowcode/commit/95cf245)).
- Исправлена невозможность сохранить страницу после удаления блока страницы из блока страницы «вкладки».
([`5addb87`](https://github.com/lowcode/lowcode/commit/5addb87)).
- Исправлена ситуация, когда условные поля отображались при просмотре записей, даже если их условие принимало значение `false`.
([`e081faa`](https://github.com/lowcode/lowcode/commit/e081faa)).

Теперь представление открывается в модальном окне, и в нём можно создать запись.

([`ac9bc74`](https://github.com/lowcode/lowcode/commit/ac9bc74)).

([`773beaf`](https://github.com/lowcode/lowcode/commit/773beaf)).

([`1354`](https://github.com/lowcode/lowcode/pull/1354)).
- Исправлена невозможность редактировать выражение рабочего процесса после клика по вкладке/окну браузера.

- Исправлена видимость опции встроенного редактора записей в списке записей: теперь она скрыта, если модуль не указан.

# `2023.3.4`

**Дата выпуска**: `2023.07.20`

.[#2023*03*04-added]#[2023*03*04-added,Добавлено:](#2023*03*04-added,Добавлено:)#
- Добавлена кнопка, позволяющая пользователю редактировать значения записей в блоке записи без необходимости открывать запись в режиме редактирования.
Изменение было добавлено, чтобы дать пользователю возможность легко редактировать одно поле при просмотре записи.
([`1282`](https://github.com/lowcode/lowcode/pull/1282)).
- Добавлены опции увеличения и скачивания файла из записи.
Изменение было добавлено, чтобы дать пользователю возможность предпросматривать и скачивать файлы при просмотре записи.
([`1310`](https://github.com/lowcode/lowcode/pull/1310)).
- Добавлены новые способы отображения полей модуля «выбор», позволяющие показывать настроенные опции в виде флажков или радиокнопок.
Изменение было добавлено, чтобы предоставить пользователю дополнительные способы просмотра значения/значений поля «выбор».
([`1301`](https://github.com/lowcode/lowcode/pull/1301)).
- Добавлена возможность использования значения записи в заголовке страницы записи.
Изменение было добавлено, чтобы дать пользователю свободу настройки заголовка страницы записи с помощью значений записей.
([`1332`](https://github.com/lowcode/lowcode/pull/1332)).
- Добавлена опция отображения флажка в виде переключателя.
Изменение было добавлено, чтобы дать пользователю ещё один способ взаимодействия с полем-флажком.
([`1286`](https://github.com/lowcode/lowcode/pull/1286)).

.[#2023*03*04-changed]#[2023*03*04-changed,Изменено:](#2023*03*04-changed,Изменено:)#
- Изменена операция восстановления роли: теперь она отправляет события обновления роли в шину событий.
Изменение было внесено для согласованности с другими операциями над ресурсами.
([`6558efc`](https://github.com/lowcode/lowcode/commit/6558efc)).
- Изменён поток аутентификации LowCoooode: теперь пропускаются ненужные экраны, и пользователь как можно быстрее попадает в запрошенное веб-приложение.
Изменение было внесено для улучшения пользовательского интерфейса и опыта аутентификации.
([`1284`](https://github.com/lowcode/lowcode/pull/1284)).

.[#2023*03*04-fixed]#[2023*03*04-fixed,Исправлено:](#2023*03*04-fixed,Исправлено:)#
- Исправлена обработка входных параметров для фильтра прокси интеграционного шлюза.
Теперь в фильтре прокси можно использовать всю область конвейера интеграционного шлюза.
([`1e82fc0`](https://github.com/lowcode/lowcode/commit/1e82fc0)).
- Исправлен неправильный приоритет условий при фильтрации списка записей оператором `Not equal`.
([`1300`](https://github.com/lowcode/lowcode/pull/1300)).
- Исправлено появление предупреждения об изменении пространства имён в Low Code только при уходе со страницы и наличии несохранённых изменений.
Раньше предупреждение появлялось после сохранения изменений при создании или обновлении пространства имён.
([`1298`](https://github.com/lowcode/lowcode/pull/1298)).
- Исправлена ситуация, когда участники роли не показывались при просмотре или редактировании роли.
([`1296`](https://github.com/lowcode/lowcode/pull/1296)).
- Исправлена ошибка, мешавшая пользователям возвращаться к списку ролей после просмотра/редактирования контекстуальной роли.
([`1307`](https://github.com/lowcode/lowcode/pull/1307)).
- Исправлен экспорт списка записей, который не включал все активные фильтры, что приводило к несогласованному выводу.
([`1318`](https://github.com/lowcode/lowcode/pull/1318)).
- Исправлена невозможность увеличивать несохранённые блоки страниц.
([`1289`](https://github.com/lowcode/lowcode/pull/1289), [`1291`](https://github.com/lowcode/lowcode/pull/1291)).
- Исправлена ситуация, когда переводы выбора поля модуля не сохранялись при настройке поля.
([`311c879`](https://github.com/lowcode/lowcode/commit/311c879)).
- Исправлена ситуация, когда валидации полей модуля на уникальность значений не сохранялись при настройке поля.
([`295defc`](https://github.com/lowcode/lowcode/commit/295defc)).
- Исправлена ситуация, когда значение даты и времени не сохранялось при создании клиента аутентификации.
([`1337`](https://github.com/lowcode/lowcode/pull/1337), [`3ed432e`](https://github.com/lowcode/lowcode/commit/3ed432e), [`bd0a941`](https://github.com/lowcode/lowcode/commit/bd0a941)).
- Исправлено положение меню действий (трёх точек) в списках диаграмм, модулей и пространств имён compose: теперь оно всегда видно при наведении, даже если столбец списка не виден.
([`1331`](https://github.com/lowcode/lowcode/pull/1331)).

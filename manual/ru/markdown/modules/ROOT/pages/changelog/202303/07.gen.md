# `2023.3.7`

**Дата выпуска**: `2023.10.04`

.[#2023*03*07-added]#[2023*03*07-added,Добавлено:](#2023*03*07-added,Добавлено:)#
- Добавлена опция удаления предустановленного фильтра из выпадающего списка предустановленных фильтров в списке записей для ролей администратора.
Изменение было добавлено, чтобы предоставить всем пользователям с ролью администратора возможность окончательно удалять предустановленный фильтр.
([`1449`](https://github.com/lowcode/lowcode/pull/1449)).
- Добавлена опция сортировки системных полей (`ownedBy`, `createdBy`, `updatedBy` и `deletedBy`), а также полей пользователей и записей в списках записей.
Изменение было добавлено, чтобы упростить пользователю сортировку/просмотр данных.
([`1449`](https://github.com/lowcode/lowcode/pull/1449)).

.[#2023*03*07-changed]#[2023*03*07-changed,Изменено:](#2023*03*07-changed,Изменено:)#
- Изменена опция клонирования макета страницы: добавлены две подопции — клонирование страницы со ссылкой на блок страницы и клонирование страницы без ссылки на блок страницы.
При клонировании со ссылкой изменения конфигурации, внесённые в блоки исходной страницы, также отражаются в блоках страниц скопированной страницы.
А при клонировании без ссылки изменения, внесённые в блоки исходной страницы, не отражаются в блоках страниц скопированной страницы.
Изменение было внесено, чтобы дать пользователю возможность выбирать, должна ли конфигурация блоков скопированной страницы использоваться совместно между страницами.
([`1444`](https://github.com/lowcode/lowcode/pull/1444)).
- Изменён интерфейс загрузки пространства имён: теперь показывается индикатор загрузки, пока обрабатываются данные, и скрываются поля имени и handle пространства имён, вместо одновременного показа индикатора загрузки и полей.
Изменение было внесено для согласованности с интерфейсом в LowCoooode.
([`c997655`](https://github.com/lowcode/lowcode/commit/c997655)).
- Изменено поле handle пользователя: оно больше не является обязательным при обновлении ресурса в Admin.
([`ed377a7`](https://github.com/lowcode/lowcode/commit/ed377a7)).
- Внесены общие улучшения UI/UX:
** Добавлена дополнительная информация о том, как писать условия для скрытия или показа макета страницы в конфигураторе макета страницы.
** Обновлён значок редактирования в дереве страниц, чтобы он совпадал со значком редактирования, используемым везде в LowCoooode.
** Стандартизирована кнопка разрешений в Admin и Low Code.
([`d2cc2c8`](https://github.com/lowcode/lowcode/commit/d2cc2c8), [`d5f8faa`](https://github.com/lowcode/lowcode/commit/d5f8faa), [`86c12cc`](https://github.com/lowcode/lowcode/commit/86c12cc)).

.[#2023*03*07-fixed]#[2023*03*07-fixed,Исправлено:](#2023*03*07-fixed,Исправлено:)#
- Исправлена ситуация, когда блоки страниц, не связанные с записями, не обновлялись в модальном окне после добавления или редактирования записи.
([`1444`](https://github.com/lowcode/lowcode/pull/1444)).
- Исправлена ситуация, когда запрос `refresh all record values` в рабочих процессах не обновлял значения записей при выполнении рабочего процесса.
([`1445`](https://github.com/lowcode/lowcode/pull/1445)).
- Исправлена ситуация, когда содержимое страницы не показывалось при создании записи в увеличенном модальном окне.
([`55dfcb8`](https://github.com/lowcode/lowcode/commit/55dfcb8)).
- Исправлена ситуация, когда блоки страниц не обновлялись с правильными данными после обновления записи.
([`8c6c3b8`](https://github.com/lowcode/lowcode/commit/8c6c3b8)).
- Исправлена ситуация, когда получение записей не возвращало все доступные страницы в случае, если правила RBAC отфильтровывали большую часть.
Исправление внесено путём отслеживания как включённых, так и исключённых записей и соответствующей корректировки логики завершения.
([`8e03ea5`](https://github.com/lowcode/lowcode/commit/8e03ea5)).

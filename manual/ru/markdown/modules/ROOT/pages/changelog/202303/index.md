# `2023.3`

С LowCoooode `2023.3` мы продолжаем улучшать стабильность системы, безопасность и производительность, а также уделяем внимание улучшению пользовательских интерфейсов, чтобы сделать LowCoooode более приятным как в использовании, так и в настройке.

**Макеты страниц**

**Макеты страниц** позволяют динамически изменять содержимое в зависимости от того, кто, что и откуда просматривает.

Вы можете определить произвольное количество и последовательность макетов страниц, что обеспечивает большую гибкость для настройки пользовательского опыта.
В дополнение к изменению макета при посещении страницы пользователем, вы также можете определить их взаимосвязь и разрешить пользователям навигацию между ними.

**Условные поля**

**Условные поля** позволяют динамически скрывать части информации на основе содержимого страницы.
Это позволяет упростить пользовательские интерфейсы и скрыть нерелевантную информацию.

**Новые блочные элементы страниц**

- **Блочный элемент «Навигация»** позволяет определить пользовательскую навигацию внутри ваших приложений Low Code.
Навигация может быть дополнением к предопределённой или полной её заменой.
- **Блочный элемент с вкладками** позволяет *упаковать* несколько блочных элементов страницы в один, *скрытый* за вкладками.
Блочный элемент с вкладками позволяет сжимать пользовательские интерфейсы, *скрывая* общие части информации за одним и тем же блочным элементом.

**Доработки UI**

Пользовательские интерфейсы были в центре внимания релиза `2023.3`; улучшение пользовательского опыта при настройке и взаимодействии с приложением, а также закладка основы для будущих релизов.

.Администрирование:
- Переработанное модальное окно конфигурации блочного элемента списка записей, которое теперь выглядит лучше и соответствует нашим стандартам стиля.
- Добавлена поддержка прикрепления иконок к страницам для улучшения внешнего вида навигации.
- Добавлена поддержка копирования, вставки и клонирования страниц и блочных элементов страниц для ускорения создания дашбордов.
- Добавлен упрощённый способ изменения экранов аутентификации без необходимости изменять исходные шаблоны.
Веб-приложение администрирования теперь позволяет вставлять пользовательский CSS и менять фоновое изображение.

.Доработки UI для конечных пользователей:
- Добавлена базовая опция детализации диаграммы, позволяющая фильтровать списки записей на основе взаимодействия с диаграммой.
- Добавлена возможность открытия записей в модальных окнах для удобства опытных пользователей.
- Добавлена возможность открытия конкретных блочных элементов страниц в модальном окне или на полный экран.
- Добавлена поддержка навигации между записями при просмотре записи.
- Добавлена поддержка массового обновления значений конкретных записей.

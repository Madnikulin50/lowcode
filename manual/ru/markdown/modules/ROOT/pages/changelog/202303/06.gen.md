# `2023.3.6`

**Дата выпуска**: `2023.09.13`

.[#2023*03*06-added]#[2023*03*06-added,Добавлено:](#2023*03*06-added,Добавлено:)#
- Добавлена функция splice в рабочих процессах, которая может изменять содержимое `массива`, удаляя или заменяя существующие элементы разных типов, таких как `strings`, `numbers`, `booleans`, `objects`, `arrays`, и/или добавляя новые элементы на месте.
Изменение было добавлено, чтобы дать возможность легко добавлять или удалять элементы из `массива`.
([`7bc36eb`](https://github.com/lowcode/lowcode/commit/7bc36eb)).
- Добавлена опция получения данных для блока страницы «геометрия» при нажатии кнопки обновления в блоке страницы или по истечении заданного пользователем времени.
Изменение было добавлено, чтобы дать возможность легко получать данные для блока страницы.
([`f189c43`](https://github.com/lowcode/lowcode/commit/f189c43)).
- Добавлен выпадающий список для просмотра разрешений конкретного модуля, страницы или макета страницы.
Изменение было добавлено, чтобы дать возможность просматривать разрешения ресурса без необходимости заходить в него.
([`7fdc854`](https://github.com/lowcode/lowcode/commit/7fdc854)).

.[#2023*03*06-changed]#[2023*03*06-changed,Изменено:](#2023*03*06-changed,Изменено:)#
- Внесены общие улучшения UI/UX:
** Кнопка сохранения в списке разрешений Admin зафиксирована, чтобы пользователю не приходилось прокручивать страницу вниз для сохранения изменений.
** Удалён лишний отступ сверху поля блока страницы записи, когда оно редактируется и не выровнено по горизонтали.
** Скрыта опция показа значений времени в обычной диаграмме, если такие значения не используются в диаграмме.
([`d924903`](https://github.com/lowcode/lowcode/commit/d924903), [`65b6db3`](https://github.com/lowcode/lowcode/commit/65b6db3), [`fd5afbb`](https://github.com/lowcode/lowcode/commit/fd5afbb)).

.[#2023*03*06-fixed]#[2023*03*06-fixed,Исправлено:](#2023*03*06-fixed,Исправлено:)#
- Исправлена ошибка неверной комбинации имени пользователя и пароля при регистрации, возникающая при попытке создать пользователя с уже существующим handle.
([`1413`](https://github.com/lowcode/lowcode/pull/1413)).
- Исправлена ситуация, когда предфильтр в блоке страницы «прогресс-бар» не возвращал никаких данных, если записи фильтруются по `recordID`.
([`1414`](https://github.com/lowcode/lowcode/pull/1414)).
- Исправлено перенаправление на список пространств имён/страниц/модулей вместо предыдущей страницы после нажатия кнопки btn:[Сохранить и закрыть] при создании или редактировании пространства имён/страницы/модуля.
([`1387`](https://github.com/lowcode/lowcode/pull/1387), [`abe1eb6`](https://github.com/lowcode/lowcode/commit/abe1eb6)).
- Исправлена ситуация, когда боковое меню с отчётами не открывалось в Reporter при наведении курсора на его значок «полосы открытия».
([`1425`](https://github.com/lowcode/lowcode/pull/1425)).
- Исправлено некорректное количество страниц, отображаемых при включённых опциях полной навигации по страницам и показа общего количества записей в списке записей.
([`1417`](https://github.com/lowcode/lowcode/pull/1417)).
- Исправлено срабатывание сообщения о несохранённых изменениях при попытке покинуть страницу настроек Low Code в Admin после сохранения изменений в настройках пользовательского интерфейса.
([`1429`](https://github.com/lowcode/lowcode/pull/1429)).
- Исправлены отсутствующие разрешения макетов страниц для аутентифицированной роли и роли администратора.
Исправление внесено путём добавления разрешений ролям.
([`2c7e972`](https://github.com/lowcode/lowcode/commit/2c7e972)).

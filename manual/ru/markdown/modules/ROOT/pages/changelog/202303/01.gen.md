# `2023.3.1`

**Дата выпуска**: `2023.05.18`

.[#2023*03*01-added]#[2023*03*01-added,Добавлено:](#2023*03*01-added,Добавлено:)#
- Добавлена возможность детализации метрик путём нажатия на элемент данных внутри блока метрик.
В зависимости от конфигурации это может либо отфильтровать существующий список записей на странице, показывающий записи из того же модуля, что и метрика, либо открыть новый список записей в модальном окне.
Изменение было добавлено, чтобы пользователям было проще фильтровать списки записей на основе данных метрик для просмотра деталей этих данных.
([`1184`](https://github.com/lowcode/lowcode/pull/1184)).
- Добавлена поддержка открытия записей блоков «геометрия» и «органайзер записей» в модальном окне.
Изменение было добавлено, чтобы дать пользователям возможность открывать записи в модальном окне, не покидая текущую страницу.
([`1177`](https://github.com/lowcode/lowcode/pull/1177)).
- Добавлена поддержка сообщений об обработке ошибок внутри рабочих процессов, позволяющая конфигураторам получать доступ к контексту сообщения об ошибке.
Изменение было добавлено, чтобы дать пользователю больше свободы в определении обработки ошибок и знании того, где и на каком шаге произошла ошибка.
([`1088`](https://github.com/lowcode/lowcode/pull/1088)).
- Добавлено добавление http-префиксов ко всем значениям URL-ввода в LowCoooode, если они не указаны пользователем.
Изменение было добавлено, чтобы пользователям было проще задавать URL без указания части http://.
([`1188`](https://github.com/lowcode/lowcode/pull/1188)).

.[#2023*03*01-changed]#[2023*03*01-changed,Изменено:](#2023*03*01-changed,Изменено:)#
- Изменено разрешение значений селектора записей: теперь оно выполняется для каждого блока страницы, а не для каждого поля, чтобы не выполнялось избыточных запросов.
Изменение было внесено для повышения производительности на медленных соединениях/системах.
Изменение внесено путём переноса разрешения на уровень блока страницы вместо уровня поля, как было раньше.
([`1176`](https://github.com/lowcode/lowcode/pull/1176)).
- Изменена боковая панель Low Code и Reporter: теперь прокручиваются только элементы, а строка поиска и кнопки публичной/админ-страницы всегда сверху.
Изменение было внесено для улучшения доступности строки поиска и кнопок публичной и админ-страницы.
Изменение внесено путём закрепления компонентов боковой панели сверху.
([`1189`](https://github.com/lowcode/lowcode/pull/1189)).

.[#2023*03*01-fixed]#[2023*03*01-fixed,Исправлено:](#2023*03*01-fixed,Исправлено:)#
- Исправлена ситуация, когда элементы диаграмм и отчётов, использующие агрегацию, выдавали ошибку.
Проблема была вызвана тем, что драйвер sqlserver ещё не поддерживает выгрузку шагов агрегации.
Исправление внесено путём сохранения агрегации на уровне приложения до тех пор, пока не будут решены несколько блокирующих проблем.
([`f931275`](https://github.com/lowcode/lowcode/commit/f931275)).
- Исправлен шаг подготовки, сообщающий о некорректном SQL-выражении.
Проблема была вызвана функцией подготовки, которая использовала сырой SQL, несовместимый с sqlserver.
Исправление внесено путём пропуска этой подготовки на sqlserver, потому что для этого драйвера она не нужна.
Драйвер был введён вместе с изменением структуры, поэтому он не нужен.
([`1d4ab0b`](https://github.com/lowcode/lowcode/commit/1d4ab0b)).
- Исправлена ошибка типизации SQL при первичной подготовке на драйвере базы данных sqlserver.
Исправление внесено путём корректной обработки и установки значений меток времени по умолчанию.
([`7675e5d`](https://github.com/lowcode/lowcode/commit/7675e5d)).
- Исправлена ситуация, когда заголовки блока вкладок стирались после добавления нового блока в список.
Исправление внесено путём отказа от обновления заголовка при создании блока.
([`1170`](https://github.com/lowcode/lowcode/pull/1170)).

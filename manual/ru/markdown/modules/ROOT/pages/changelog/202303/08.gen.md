# `2023.3.8`

**Дата выпуска**: `2023.10.18`

.[#2023*03*08-changed]#[2023*03*08-changed,Изменено:](#2023*03*08-changed,Изменено:)#
- Изменена подсистема импорта записей: она модернизирована с помощью новой платформы преобразования данных.
Изменение было внесено для оптимизации процесса импорта записей, сделав его более стабильным, эффективным и способным обрабатывать большие объёмы импортов записей.
([`399f9a7`](https://github.com/lowcode/lowcode/commit/399f9a7)).

.[#2023*03*08-fixed]#[2023*03*08-fixed,Исправлено:](#2023*03*08-fixed,Исправлено:)#
- Исправлена ситуация, когда импорт записей ничего не импортировал без сообщений об ошибках.
Исправление внесено путём исправления управления файлами для корректного сообщения о строках и количестве.
Проблема была вызвана тем, что состояние не сбрасывалось корректно после выполнения *preflight* для анализа и подсчёта записей.
([`532e1ac`](https://github.com/lowcode/lowcode/commit/532e1ac)).
- Исправлена ошибка неопределённого свойства в консоли разработчика при удалении блока страницы.
([`1476`](https://github.com/lowcode/lowcode/pull/1476)).
- Исправлена ошибка дублирующихся ключей идентификации в консоли разработчика при настройке кнопок автоматизации.
([`28d4d0d`](https://github.com/lowcode/lowcode/commit/28d4d0d)).
- Исправлена ситуация, когда элемент метрики не соблюдал свою конфигурацию формата и отображался как целое число по умолчанию в Reporter.
([`1421`](https://github.com/lowcode/lowcode/pull/1421)).
- Исправлена ситуация, когда выражения макета страницы не вычислялись при переключении с редактирования на просмотр записи.
Это исправление также решило проблему отсутствия объекта записи при начальной загрузке.
([`1475`](https://github.com/lowcode/lowcode/pull/1475)).

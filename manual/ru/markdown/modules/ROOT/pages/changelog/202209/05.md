# `2022.9.5`

**Релиз состоялся**: `2022.12.22`

.[#2022*09*05-added]#[2022*09*05-added,Добавлено:](#2022*09*05-added,Добавлено:)*
- Добавлены отсутствующие опции конфигурации, которые были в диаграммах compose, но отсутствовали в диаграммах репортёра: легенда, всплывающая подсказка, смещение, поворот меток по осям X и Y.
Изменение добавлено для предоставления одинакового набора функций в обоих конфигураторах диаграмм
([`d8fa5be`](https://github.com/lowcode/lowcode/commit/d8fa5be)).
- Добавлена функция INSTR, которую можно использовать в предфильтрах compose: INSTR('foobar', 'foo').
Она возвращает позицию первого вхождения второго параметра в первом, начиная с 1.
Возвращает 0, если совпадение не найдено; поиск регистронезависимый.
Изменение добавлено для обеспечения большей гибкости предфильтров compose
([`36d8fc6`](https://github.com/lowcode/lowcode/commit/36d8fc6)).

.[#2022*09*05-changed]#[2022*09*05-changed,Изменено:](#2022*09*05-changed,Изменено:)*
- Отключено перетаскивание в средстве выбора полей при поиске поля в процессе настройки модулей, диаграмм и полей страниц.
Изменение сделано, потому что переупорядочивание полей во время поиска вызывало проблемы.
Изменение внесено путём добавления вычисляемого свойства, отслеживающего, добавлен ли параметр запроса и отключено ли перетаскивание
([`a0a7031`](https://github.com/lowcode/lowcode/commit/a0a7031)).
- Селекторы столбцов в репортёре (предфильтр, метка/первичный/вторичный столбец) теперь показывают метку и имя столбца, а также поддерживают поиск, за исключением предсортировки.
Изменение сделано для упрощения различения полей с одинаковыми метками, например, после использования объединения.
Изменение внесено путём замены стандартного Bootstrap Select на компонент Vue-Select
([`e61cfde`](https://github.com/lowcode/lowcode/commit/e61cfde)).
- Операторы фильтрации «больше чем» и «меньше чем» теперь доступны только для числовых полей и полей даты.
Операторы «Содержит» и «Не содержит» теперь доступны только для полей с множественными значениями.
Изменение сделано для предотвращения использования неподдерживаемых операторов фильтрации для конкретных типов полей.
Изменение внесено путём обновления конфигурации списка операторов в фильтре списка записей
([`713`](https://github.com/lowcode/lowcode/pull/713), [`713`](https://github.com/lowcode/lowcode/pull/713)).

.[#2022*09*05-fixed]#[2022*09*05-fixed,Исправлено:](#2022*09*05-fixed,Исправлено:)*
- Исправлена фильтрация для логического типа с операторами равно и не равно.
Исправление добавлено путём создания пользовательского обработчика значений для логического типа для корректного преобразования при разборе запроса в соответствии с поддерживаемыми драйверами
([`8e5d63c`](https://github.com/lowcode/lowcode/commit/8e5d63c)).
- Исправлено восстановление уровня чувствительности, которое вызывало ошибку «не найдено» из-за некорректного HTTP-запроса.
Исправление корректно обрабатывает различные состояния уровня чувствительности для вызова правильного эндпоинта
([`7eb26e6`](https://github.com/lowcode/lowcode/commit/7eb26e6)).
- Исправлено неприменение правил RBAC при их назначении через рабочие процессы при указании роли через тип Role.
Рабочий процесс не вызывал ошибок, но сохранённое правило RBAC было недействительным (roleID был установлен в 0).
Исправление обновляет код обработчика автоматизации для проверки всех поддерживаемых типов, а не только roleID
([`6a14808`](https://github.com/lowcode/lowcode/commit/6a14808)).
- Исправлено неотображение списка страниц в состоянии загрузки во время получения страниц.
Исправление добавлено путём отображения спиннера с текстом «Загрузка»
([`671`](https://github.com/lowcode/lowcode/pull/671)).
- Исправлено необновление списка ресурсов после импорта нового ресурса.
Исправление добавлено путём функции обновления, которая повторно получает список ресурсов
([`f2f9032`](https://github.com/lowcode/lowcode/commit/f2f9032)).
- Исправлено переполнение диаграммой блока при использовании диаграммы репортёра внутри блочного элемента страницы compose, если блок имел заголовок.
Исправление использует тот же макет, что и в обычных диаграммах compose
([`c09e0f5`](https://github.com/lowcode/lowcode/commit/c09e0f5)).
- Исправлен некорректный заголовок модального окна разрешений, если у ресурса не было заголовка или handle.
Исправление гарантирует, что ID ресурса будет отображаться в заголовке модального окна разрешений, если нет другой идентифицирующей информации
([`fd76c8f`](https://github.com/lowcode/lowcode/commit/fd76c8f)).

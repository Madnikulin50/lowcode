# `2022.9.4`

**Релиз состоялся**: `2022.12.08`

.[#2022*09*04-added]#[2022*09*04-added,Добавлено:](#2022*09*04-added,Добавлено:)*
- Добавлена поддержка объединённой сортировки для всех поддерживаемых драйверов хранилища.
Изменение добавлено для сортировки первого ненулевого значения среди заданных столбцов в один столбец
([`547`](https://github.com/lowcode/lowcode/pull/547)).
- Добавлена кнопка тестирования SMTP-сервера для настроек email в администрировании.
Изменение добавлено, чтобы администраторы могли проверить корректность конфигурации SMTP перед развёртыванием изменений
([`539`](https://github.com/lowcode/lowcode/pull/539)).
- Добавлена интеграция Nylas, позволяющая легко подключать LowCoooode к провайдерам email, календаря и контактов.
Добавлен новый блочный элемент страницы в compose под названием Nylas, который может отображать компоненты Nylas, определённые в панели управления Nylas.
Внешний провайдер Nylas также добавлен в список в панели администрирования в разделе «Системные настройки».
Изменение добавлено для обеспечения интеграции с Nylas и поддержки использования его компонентов внутри Low Code
([`539`](https://github.com/lowcode/lowcode/pull/539)).

.[#2022*09*04-changed]#[2022*09*04-changed,Изменено:](#2022*09*04-changed,Изменено:)*
- Изменено отображение меток в блочном элементе метрики: теперь отображаются метки вместо имён.
Изменение сделано, потому что ранее некорректно отображались имена полей вместо их меток.
Изменение внесено путём замены отображения полей блочного элемента метрики на метки вместо имён
([`586`](https://github.com/lowcode/lowcode/pull/586)).

.[#2022*09*04-fixed]#[2022*09*04-fixed,Исправлено:](#2022*09*04-fixed,Исправлено:)*
- Исправлена сортировка последнего столбца изменений в списках пространств имён, модулей, страниц, рабочих процессов и репортёров.
Ранее сортировка выполнялась по значению updatedAt, и значение отображалось как updatedAt или createdAt, если ресурс ещё не был обновлён.
Исправление использует объединение (`deletedAt`, `updatedAt`, `createdAt`) для сортировки по всем трём столбцам, чтобы отображаемое значение соответствовало значению, используемому для сортировки
([`547`](https://github.com/lowcode/lowcode/pull/547)).
- Исправлен некорректный порядок данных в диаграммах Low Code, вызванный неправильным упорядочиванием данных в эндпоинте отчёта записей.
Исправление добавлено путём явной сортировки по указанному полю измерения
([`956e30e`](https://github.com/lowcode/lowcode/commit/956e30e)).
- Исправлена невозможность перехода на предыдущую страницу в таблицах репортёра.
Исправление обновляет курсор страницы только при его существовании при создании фильтра пагинации отчёта для сохранения корректного курсора для следующей страницы
([`588`](https://github.com/lowcode/lowcode/pull/588)).
- Исправлена невозможность закрыть модальное окно рабочего процесса после нажатия «Новый рабочий процесс».
Исправление добавляет кнопку «Назад», имитирующую поведение кнопки «Назад» браузера
([`585`](https://github.com/lowcode/lowcode/pull/585)).
- Исправлена некорректная настройка элемента отображения диаграммы репортёра при создании, если тип диаграммы был изменён.
Исправление корректно обновляет опции элемента отображения диаграммы при изменении типа диаграммы
([`074b2fd`](https://github.com/lowcode/lowcode/commit/074b2fd)).

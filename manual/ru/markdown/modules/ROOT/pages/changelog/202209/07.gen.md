# `2022.9.7`

**Дата выпуска**: `2023.02.10`

.[#2022*09*07-added]#[2022*09*07-added,Добавлено:](#2022*09*07-added,Добавлено:)#
- Добавлена поддержка приведения чисел к float внутри выражений рабочего процесса с помощью функции `float`.
Изменение было добавлено, чтобы упростить приведение типов с помощью функции вместо промежуточной переменной выражения рабочего процесса.
([`38b6cb3`](https://github.com/lowcode/lowcode/commit/38b6cb3)).
- Добавлена возможность переключать рамку блока.
Изменение было добавлено, чтобы лучше различать блоки, когда они не показаны как карточки.
([`860`](https://github.com/lowcode/lowcode/pull/860)).
- Добавлены общие улучшения UI/UX.
Изменение было добавлено, чтобы сделать невозможными некоторые некорректные конфигурации, улучшить обзор некоторых ресурсов и подготовить стили и макеты для будущих релизов.
([`80117c0`](https://github.com/lowcode/lowcode/commit/80117c0), [`ef7e864`](https://github.com/lowcode/lowcode/commit/ef7e864), [`9acc109`](https://github.com/lowcode/lowcode/commit/9acc109)).

.[#2022*09*07-changed]#[2022*09*07-changed,Изменено:](#2022*09*07-changed,Изменено:)#
- Изменено: свойство name стало обязательным при создании шаблонов, подключений dal, рабочих процессов, клиентов аутентификации и уровней чувствительности.
Изменение было внесено, потому что раньше можно было создать ресурс без ввода каких-либо данных, а с этим изменением появилось требование, и теперь нельзя создать ресурс без ввода данных.
Изменение внесено путём добавления валидаций, препятствующих созданию одного из перечисленных ресурсов без указания имени.
([`38a02d5`](https://github.com/lowcode/lowcode/commit/38a02d5)).
- Изменено использование chart.js на панели администратора на e-charts.
Изменение было внесено, чтобы удалить все места, где мы использовали chart.js, так как мы перешли на apache e-charts.
Изменение внесено путём замены диаграммы на панели администратора на e-charts.
([`7daafa1`](https://github.com/lowcode/lowcode/commit/7daafa1)).

.[#2022*09*07-fixed]#[2022*09*07-fixed,Исправлено:](#2022*09*07-fixed,Исправлено:)#
- Исправлена невозможность использования органайзера записей на странице записи.
Исправление внесено путём корректной загрузки после того, как объект записи становится доступен, и предоставления эталонной записи, чтобы значения можно было предварительно заполнить.
([`2398499`](https://github.com/lowcode/lowcode/commit/2398499)).
- Исправлен тип данных столбца ID в PSQL с `BIGINT` на numeric для поддержки типа данных ID uint64 в LowCoooode.
Исправление внесено путём изменения типа данных для ID в PostgreSQL с bigint на numeric.
([`830`](https://github.com/lowcode/lowcode/pull/830)).
- Исправлена ситуация, когда аутентифицированная роль перезаписывалась при перезапуске сервера, если роль была изменена.
Исправление внесено путём добавления проверки в логику подготовки, чтобы пропускать базовые роли и правила RBAC, если они уже были подготовлены.
([`88204f7`](https://github.com/lowcode/lowcode/commit/88204f7)).
- Исправлена ситуация, когда таблица фильтров интеграционного шлюза не показывала все доступные данные при загрузке.
Исправление внесено путём добавления флага обработки в таблицу фильтров интеграционного шлюза, чтобы она корректно запускала обновление при изменении фильтров.
([`cfe7e50`](https://github.com/lowcode/lowcode/commit/cfe7e50)).
- Исправлена ситуация, когда средство выбора полей настроек discovery не разбирало сохранённые значения.
Исправление внесено путём переноса настроек discovery на поддержку нескольких языков и обновления структуры конфигурации модуля discovery для поддержки многоязычного результата.
([`724804c`](https://github.com/lowcode/lowcode/commit/724804c), [`e020f74`](https://github.com/lowcode/lowcode/commit/e020f74)).
- Исправлен фильтр списка записей по дате, который не показывал никаких записей, если у вас есть поле только с датой, и вы устанавливаете фильтр равным правильному дню.
Также при настройке фильтра «только время» и «прошлые значения» конфигурация учитывала только часы, потому что даже если минуты были в прошлом, форма считалась недействительной, пока не менялся час.
Исправлена ошибка `Could not load record list: pq: cannot cast type time with time zone to timestamp with time zone` при наличии значения только времени и попытке фильтрации с помощью фильтра времени.
Исправление внесено путём обновления построителя фильтра списка записей с корректным элементом запроса для «только времени» и «только даты».
([`847`](https://github.com/lowcode/lowcode/pull/847)).
- Исправлена ситуация, когда тип даты и времени в версиях записей отображался как kind.datetime.label.
Исправление внесено путём обновления перевода раздела типа в конфигураторе версий записей для отображения полей в camel case, что соответствует дате и времени в самом переводе.
([`863`](https://github.com/lowcode/lowcode/pull/863)).
- Исправлен экспорт рабочего процесса без handle, который приводил к имени файла json.json.
Исправление внесено путём отката к имени рабочего процесса и санитизации имени файла от недопустимых символов перед сохранением.
([`96f8bc5`](https://github.com/lowcode/lowcode/commit/96f8bc5)).

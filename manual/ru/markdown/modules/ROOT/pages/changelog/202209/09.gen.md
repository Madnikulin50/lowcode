# `2022.9.9`

**Дата выпуска**: `2023.04.05`

.[#2022*09*09-added]#[2022*09*09-added,Добавлено:](#2022*09*09-added,Добавлено:)#
- Добавлена пагинация во встроенных списках записей в режиме просмотра.
Изменение было добавлено для согласованности и лучшего пользовательского опыта при встроенном редактировании записей.
([`e0ae508`](https://github.com/lowcode/lowcode/commit/e0ae508)).

.[#2022*09*09-changed]#[2022*09*09-changed,Изменено:](#2022*09*09-changed,Изменено:)#
- Изменено модальное окно импорта записей, чтобы пользователи могли сопоставлять значения с полями записей и пользователей.
Изменение было внесено, чтобы пользователи могли сопоставлять значения с полями записей и пользователей при импорте записей.
Изменение внесено путём удаления кода, который мешал пользователям сопоставлять значения с полями записей и пользователей.
([`0cf81dc`](https://github.com/lowcode/lowcode/commit/0cf81dc)).
- Изменены триггеры рабочего процесса, чтобы они больше не добавляли ограничения автоматически после выбора типа события.
Изменение было внесено, чтобы предотвратить появление ошибки в консоли у пользователей при получении триггеров рабочего процесса без указанных ограничений.
([`7a9802a`](https://github.com/lowcode/lowcode/commit/7a9802a)).

.[#2022*09*09-fixed]#[2022*09*09-fixed,Исправлено:](#2022*09*09-fixed,Исправлено:)#
- Исправлена ошибка `Cannot read properties of undefined` при попытке получить триггеры рабочего процесса без указания ограничений.
Исправление внесено путём добавления проверки, определяющей, есть ли у константы имя.
Кроме того, автоматическое добавление ограничений после выбора типа события теперь удалено.
([`7a9802a`](https://github.com/lowcode/lowcode/commit/7a9802a)).
- Исправлена отсутствующая поддержка агрегатной функции STD в базах данных MySQL.
Функция STD присутствовала в предыдущих версиях.
Исправление внесено путём добавления обработчика выражения для функции и разрешения её только для баз данных MySQL.
([`3ec7d19`](https://github.com/lowcode/lowcode/commit/3ec7d19)).
- Исправлена ситуация, когда списки записей выдавали `Could not load record list: can not change module on a record` при работе с импортированным пространством имён.
Проблема была вызвана тем, что логика импорта не определяла никаких ограничений модели.
Исправление внесено путём применения ограничений модели в логике импорта при определении модели, а также определения модели версий записей.
([`a554e28`](https://github.com/lowcode/lowcode/commit/a554e28)).
- Исправлена ситуация, когда будущие/прошлые значения невозможно было выбрать, если к полю DateTime применена опция только будущих/прошлых значений.
Исправление внесено путём отключения опции «только будущие/прошлые» в фильтре списка записей.
([`24a3197`](https://github.com/lowcode/lowcode/commit/24a3197), [`ffbaba2`](https://github.com/lowcode/lowcode/commit/ffbaba2)).
- Исправлена ситуация, когда представление пользователя в Admin не показывало никаких данных после нажатия «Confirm email address».
Исправление внесено путём повторной загрузки пользователя в Admin при подтверждении адреса электронной почты.
([`e76fb09`](https://github.com/lowcode/lowcode/commit/e76fb09)).
- Исправлена ситуация, когда тип поля не обновлялся в модулях после его выбора.
Исправление внесено путём обновления типа поля модуля после его выбора.
([`1018`](https://github.com/lowcode/lowcode/pull/1018), [`1018`](https://github.com/lowcode/lowcode/pull/1018)).
- Исправлена невозможность пользователей обновлять свои записи из-за ошибки «Could not update record: failed to complete transaction: Error 1366: Incorrect decimal value: `updated` for column `operation` at row 1».
Исправление внесено путём изменения типа данных, а также перестановки столбцов таблицы версий записей для согласованности.
([`b585dfb`](https://github.com/lowcode/lowcode/commit/b585dfb)).

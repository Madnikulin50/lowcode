# `2022.9.3`

**Дата выпуска**: `2022.11.25`

.[#2022*09*03-added]#[2022*09*03-added,Добавлено:](#2022*09*03-added,Добавлено:)#
- Добавлена новая опция позиции подписи для диаграмм с осью Y.
Она позволяет разместить подпись внизу, посередине или вверху оси Y.
Изменение было добавлено, потому что подпись оси Y перекрывалась со значениями, если они были больше.
([`18248a2`](https://github.com/lowcode/lowcode/commit/18248a2)).
- Добавлены новые операторы фильтрации с несколькими значениями (`IN` и `NOT IN`) в предфильтр в интерфейсе Reporter.
Благодаря этому пользователи могут фильтровать записи с помощью полей с несколькими значениями.
Изменение было добавлено, чтобы вернуть возможность фильтровать записи по их полям с несколькими значениями внутри отчётов.
([`560`](https://github.com/lowcode/lowcode/pull/560)).
- Добавлена дополнительная конфигурация для круговых, столбчатых, линейных диаграмм и диаграмм-пончиков.
Было добавлено три новых раздела — tooltip, legend и offset, а также опции поворота подписей осей X и Y (только для столбчатых и линейных диаграмм).
Изменение было добавлено, чтобы дать пользователям больше свободы в настройке диаграмм.
([`a8d3b83`](https://github.com/lowcode/lowcode/commit/a8d3b83), [`b2c9de5`](https://github.com/lowcode/lowcode/commit/b2c9de5)).
- Добавлена поддержка установки минимального значения и значения по умолчанию (value, min и max) для полей модуля «прогресс-бар» и блоков страницы.
Изменение было добавлено, чтобы предоставить пользователю больше возможностей настройки и упростить использование прогресс-бара в LowCoooode.
([`f367836`](https://github.com/lowcode/lowcode/commit/f367836)).

.[#2022*09*03-changed]#[2022*09*03-changed,Изменено:](#2022*09*03-changed,Изменено:)#
- Изменено: теперь список ресурсов использует один и тот же компонент, количество элементов и пагинацию, и это также включено для списков ресурсов, которые это поддерживают.
Теперь почти для каждого ресурса мы показываем общее количество элементов, и у нас есть возможность перейти на следующую страницу, если есть элементы.
Изменение было внесено, потому что внешний вид списков в LowCoooode нужно было унифицировать.
А также для лучшего пользовательского опыта и чтобы всегда знать правильное количество записей/элементов.
Изменение внесено путём обновления и использования переиспользуемого компонента CResourceList в lowcode-vue.
Это означает, что мы можем управлять внешним видом всех списков из одного места.
([`030109b`](https://github.com/lowcode/lowcode-vue/commit/030109b), [`229bf12`](https://github.com/lowcode/lowcode-webapp-admin/commit/229bf12), [`c67daa7`](https://github.com/lowcode/lowcode-webapp-compose/commit/c67daa7), [`06c07d8`](https://github.com/lowcode/lowcode-webapp-reporter/commit/06c07d8), [`6033433`](https://github.com/lowcode/lowcode-webapp-workflow/commit/6033433)).
- Изменено требование указывать handle при создании ресурса — оно удалено, и handle теперь необязателен.
Изменение применяется в compose, admin, reporter и workflow.
Изменение было внесено, потому что указание handle не должно быть обязательным, и у ресурсов должна быть возможность его опустить.
Изменение внесено путём удаления строгой проверки наличия handle.
([`cd86e85`](https://github.com/lowcode/lowcode-webapp-compose/commit/cd86e85), [`cf21c47`](https://github.com/lowcode/lowcode-webapp-reporter/commit/cf21c47), [`456c896`](https://github.com/lowcode/lowcode-webapp-admin/commit/456c896), [`9b88af0`](https://github.com/lowcode/lowcode-webapp-workflow/commit/9b88af0), [`24b0dda`](https://github.com/lowcode/lowcode-locale/commit/24b0dda), [`34f261a`](https://github.com/lowcode/lowcode-vue/commit/34f261a), [`3a90a10`](https://github.com/lowcode/lowcode-js/commit/3a90a10)).
- Изменён цвет кнопки подтверждения действия по принятию запроса на обработку персональных данных.
Изменение было внесено, чтобы цвета совпадали с цветами при подтверждении/отклонении действия по отклонению запроса на обработку персональных данных.
Изменение внесено путём изменения цвета на тёмно-синий.
([`d4ed9ff`](https://github.com/lowcode/lowcode/commit/d4ed9ff)).

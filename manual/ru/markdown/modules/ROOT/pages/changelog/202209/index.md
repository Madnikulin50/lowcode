# `2022.9`

С LowCoooode `2022.9` мы продолжаем улучшать стабильность системы, безопасность, производительность, а также уделяем внимание функциям, помогающим организациям соблюдать **политики и нормативные требования** в области **конфиденциальности данных**.

**LowCoooode Privacy**

**LowCoooode privacy** предоставляет функции, помогающие организациям соблюдать политики и нормативные требования конфиденциальности данных.
С LowCoooode privacy мы стремимся упростить процесс обработки различных нормативных требований к конфиденциальности данных для low-code приложений, созданных с помощью LowCoooode.

Мы внедряем **уровни чувствительности**, которые позволяют администраторам классифицировать **какие данные являются чувствительными** и **на каком уровне их следует обрабатывать**.
Мы также представили два новых веб-приложения: **консоль конфиденциальности**, которая позволяет пользователям **просматривать** свои данные и **запрашивать изменения**, и **консоль сотрудника по защите данных**, которая позволяет **сотрудникам по защите данных** управлять запросами конфиденциальности, отправленными пользователями.

**Переопределённое хранение записей**

LowCoooode `2022.9` переопределяет способ внутреннего хранения данных для улучшения **производительности, масштабируемости и гибкости**.
LowCoooode теперь поддерживает определение администраторами **внешних баз данных** и настройку **выделенных, автономных** **мест хранения** данных для модулей.

**Обнаружение дубликатов**

Наряду с переопределённым **хранением записей** мы внедряем инструменты для **предотвращения дублирования данных**.
LowCoooode теперь позволяет администраторам указывать правила для определения, существует ли запись, и как система должна обрабатывать дубликат.
В настоящее время система может либо предупредить о дублирующейся записи, либо полностью отклонить создание записи.

**Ревизии записей**

LowCoooode теперь поддерживает настройку администраторами модулей Low Code для **отслеживания изменений** в их записях.
Изменения отслеживаются путём введения номера ревизии и предоставления полной истории модификаций для каждой записи.

!!! note
    Отслеживаются только изменения, сделанные начиная с версии `2022.9.0`.
    Предопределённые записи считаются первой ревизией.


**Отладка разрешений**

Чтобы упростить процесс настройки контроля доступа для разных ролей пользователей, мы внедрили новый **отладчик разрешений**, который позволяет администраторам проверять, соответствует ли результирующий контроль доступа ожидаемому.
Отладчик разрешений доступен во всех модальных окнах конфигурации разрешений и в общих разрешениях компонентов LowCoooode Admin.

.[#2022*9-important]#[2022*9-important,Важные примечания к обновлению:](#2022_9-important,Важные примечания к обновлению:)#
- Шаг `Group` в LowCoooode Reporter изменён на `Aggregate`, старый шаг `Join` изменён на `Link` и добавлен новый шаг `Join`.
- Функция выражения `date()` в LowCoooode Reporter изменена: теперь возвращает полную **дату без времени** (предыдущая версия возвращала номер дня), и добавлена новая функция `day()` для получения номера дня.

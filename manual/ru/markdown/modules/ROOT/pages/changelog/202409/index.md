# `2024.9`

С LowCoooode `2024.9` мы сосредоточились на улучшении основной функциональности LowCoooode путём внедрения новых опций для большей кастомизации.

Мы также оптимизировали low-code разработку, добавив интеллектуальные подсказки кода для ввода выражений, доступные как в Compose, так и в Workflows.

Заглядывая вперёд, мы планируем расширить эти функции ещё более мощными подсказками.

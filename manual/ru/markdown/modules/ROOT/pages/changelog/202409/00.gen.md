Изменение было добавлено для оптимизации редактирования записей, минуя режим просмотра
([`6fbb075`](https://github.com/lowcode/lowcode/commit/6fbb075)).
- Добавлена возможность указывать перенос текста в полях в списках записей.
Изменение было добавлено для лучшего контроля отображения текста в списках записей
([`65be113`](https://github.com/lowcode/lowcode/commit/65be113)).
- Добавлены условия видимости для блоков страниц.
Изменение было добавлено для обеспечения динамического контроля отображения блоков страниц
([`93cb166`](https://github.com/lowcode/lowcode/commit/93cb166)).
- Добавлено автодополнение в редакторах выражений, текстовых редакторах рабочих процессов и редакторе CSS брендинга.
Изменение было добавлено для упрощения редактирования путём предоставления подсказок во время ввода
([`5e2f280`](https://github.com/lowcode/lowcode/commit/5e2f280)).
- Добавлена возможность добавлять новые записи из полей редактора выбора записей.
Изменение было добавлено для повышения эффективности, позволяя создавать записи непосредственно из селектора записей
([`5f94d59`](https://github.com/lowcode/lowcode/commit/5f94d59)).
- Добавлена возможность настройки фильтров списка записей с помощью интерфейса фильтра записей.
Изменение было добавлено для предоставления более интуитивного метода настройки фильтров списка записей
([`3ebb8ac`](https://github.com/lowcode/lowcode/commit/3ebb8ac)).
- Добавлена возможность настройки переноса полей в блоках записей.
Изменение было добавлено, чтобы пользователи могли контролировать, переносятся ли поля в блоках записей или остаются на одной строке
([`a1e1b2d`](https://github.com/lowcode/lowcode/commit/a1e1b2d)).
- Добавлены таблицы в редакторе форматированного текста.
Изменение было добавлено для обеспечения использования таблиц для структурированного контента в форматированном тексте
([`0322717`](https://github.com/lowcode/lowcode/commit/0322717)).
- Добавлена возможность отключения уведомлений о сохранении на страницах записей.
Изменение было добавлено для более чистого пользовательского опыта, скрывая уведомления о сохранении
([`b744202`](https://github.com/lowcode/lowcode/commit/b744202)).
- Добавлена встроенная фильтрация для блоков списков записей на основе значений записей.
Изменение было добавлено для упрощения фильтрации, позволяя пользователям фильтровать списки без ручного ввода значений
([`a3b9b9a`](https://github.com/lowcode/lowcode/commit/a3b9b9a)).
- Добавлены живые фильтры для блоков диаграмм.
Изменение было добавлено, чтобы пользователи могли фильтровать диаграммы напрямую, без необходимости их редактирования
([`bd28b34`](https://github.com/lowcode/lowcode/commit/bd28b34)).
- Добавлены разрешения для экспорта пространств имён, модулей и диаграмм.
Изменение было добавлено для контроля того, кто имеет возможность экспортировать данные.

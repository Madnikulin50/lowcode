# Lowcode

Lowcode — самостоятельно размещаемая low-code платформа. На ней собирают рабочие приложения из пространств, модулей и страниц, не поднимая отдельный сервер под каждую задачу. Доступ к записям, страницам и действиям задаётся ролями.

Приложения, которые видит вошедший пользователь:

| Приложение | Назначение |
|---|---|
| Хаб | Список доступных приложений |
| Compose | Пространства, списки и карточки записей |
| Администрирование | Пользователи, роли, настройки, шлюз |
| Процессы | Сценарии автоматизации |
| Отчёты | Отчёты по данным Compose |
| Поиск | Поиск, если он включён на стенде |
| Конфиденциальность | Запросы субъекта данных |

Пустая установка не содержит готовых пространств. CRM, обращения и другие предметные приложения появляются после публикации в Compose.

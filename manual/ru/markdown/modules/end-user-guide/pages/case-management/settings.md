# Настройки

Страница «Настройки» доступна при нажатии на раздел меню:Настройки[] в главной навигационной панели в верхней части экрана.

## Доступные настройки

### Следующий номер элемента KB

Указывает следующий ID, который используется для соседнего элемента (записи) KB.
Если вы не переноситесь из другой системы, это значение менять не нужно.

### Стоимость за час по умолчанию

Используется, если отдел не определяет свою почасовую стоимость или если вы не назначаете отдел для обновления обращения.

!!! note
    Мы настоятельно рекомендуем, чтобы каждый отдел явно указывал почасовую стоимость.


### Отдел по умолчанию для нового тикета

Это отдел по умолчанию, который будет назначен тикету, если не выбран другой отдел.

### Время по умолчанию для обновления обращения

Это время по умолчанию, которое используется при работе над обновлениями обращений.

!!! tip
    Вы можете рассчитать среднее затраченное время и использовать это значение здесь.


### Ссылка на обращение по умолчанию

Это базовый URL, который используется при генерации ссылок на обращения.

!!! tip
    Если у вас есть внешний портал, который может отображать обращения, хранящиеся в LowCoooode, вы можете изменить эту ссылку, чтобы она указывала на этот портал.


## Пошаговая конфигурация

### Следующий номер элемента KB

Если вы перенеслись из другой системы, введите следующий номер, который следует использовать.
Если нет, вы можете оставить это как есть.

### Стоимость за час по умолчанию

Введите стоимость по умолчанию, которая должна использоваться при работе над обновлением обращения.

### Отдел по умолчанию для нового тикета

Выберите отдел по умолчанию.
Сначала создайте отделы, если вы не видите ни одного.

### Время по умолчанию для обновления обращения

Введите время по умолчанию, которое должно использоваться при работе над обновлением обращения.

### Ссылка на обращение по умолчанию

1. Перейдите к «Страницы» вашей админ-панели,
1. найдите страницу, называемую `Record page for module "Case"`,
1. скопируйте ID страницы (это длинное число в конце адреса, похожее на указанный выше ID канала),
1. вставьте `https://{APP*DOMAIN}/compose/ns/case-management/pages/<page*ID_here>/record`.
Например: `https://{APP_DOMAIN}/compose/ns/case-management/pages/111502308285612036/record`

!!! tip
    Если у вас есть внешний портал, который может отображать обращения, хранящиеся в LowCoooode, вы можете изменить эту ссылку, чтобы она указывала на этот портал.

# Продукты

Страница «Продукты» доступна при нажатии на раздел меню:Продукты[] в главной навигационной панели в верхней части экрана.

Продукт может быть физическим или программным продуктом, а также услугой, предоставляемой вашей компанией.
Продукты позволяют отслеживать, какой оборот обеспечивает конкретный продукт или семейство продуктов.
Вы также получаете обзор всех обращений для конкретного продукта.

## Добавление продукта

1. Перейдите в меню:Продукты[],
1. нажмите на кнопку btn:[+ Добавить], чтобы открыть форму,
1. заполните данные и нажмите кнопку btn:[Сохранить] в правом нижнем углу.

## Ключевые части продукта

Описание продукта::
    Здесь хранится основная информация о продукте, такая как его код продукта, название, семейство и, опционально, шаблон обслуживания обращений.

!!! tip
    Вы можете использовать шаблоны обслуживания обращений для автоматизации создания более распространённых видов обслуживания, таких как гарантия на оборудование для продукта.


Итоги по обращениям::
    Здесь можно увидеть общее время и стоимость, которые потребовал конкретный продукт на данный момент.
    Система рассчитывает эти поля, так что вам не нужно об этом беспокоиться!

Обращения, связанные с этим продуктом::
    Здесь вы можете найти все обращения, созданные для продукта.
    Это помогает выявить наиболее проблемные продукты и наиболее распространённые проблемы.

Обслуживание обращений для этого продукта::
    Здесь вы можете найти всё обслуживание обращений, созданное для этого продукта.

Элементы базы знаний, связанные с этим продуктом::
    База знаний позволяет нам предоставлять информацию о продукте, чтобы наши агенты поддержки могли давать качественные ответы без необходимости привлекать экспертов.

!!! note
    База знаний доступна с экрана создания обращения.

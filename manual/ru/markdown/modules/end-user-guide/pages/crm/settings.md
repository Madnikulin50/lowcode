# Настройки

Этот специальный модуль имеет только одну запись.
Здесь вы можете установить:

.Настройки сделок
- Дни до закрытия сделки
- Вероятность сделки по умолчанию
- Категория прогноза по умолчанию
- Стадия сделки по умолчанию

.Настройки предложений
- Следующий номер предложения
- Дни до истечения срока предложения
- Электронная почта по умолчанию для отправки предложения

.Настройки контрактов
- Следующий номер контракта
- Время контракта по умолчанию (в месяцах)

.Настройки обращений
- Следующий номер обращения
- Следующий номер решения

# Главная

Главная страница доступна при нажатии на раздел меню:Главная[] в главной навигационной панели в верхней части экрана.

Главная страница — это основная панель мониторинга вашего бизнеса; она даёт быстрый обзор наиболее важной информации в CRM.

По умолчанию она показывает вам основную статистику по вашим лидам, календарь с событиями, а также списки ваших новых лидов, ключевых сделок и задач.

# Интерфейс

У всех приложений одна верхняя панель.

| Элемент | Что делает |
|---|---|
| Меню | Сворачивает и разворачивает боковую панель |
| Название | Заголовок текущей страницы |
| Переключатель темы | Светлая или тёмная тема; выбор сохраняется в профиле |
| Колокольчик | Уведомления, если они не скрыты настройкой |
| Справка | Номер версии сборки и дополнительные ссылки, если их задал администратор |
| Аватар | Меню текущего пользователя |

## Меню аватара

В меню видно, под кем вы вошли. Дальше, в зависимости от прав и настроек:

- профиль;
- смена пароля;
- тема оформления;
- **Документация**;
- выход.

Раздел «Документация» раскрывается и содержит три ссылки. Каждая открывается в новой вкладке.

| Пункт | Что открывается |
|---|---|
| Документация пользователя | Это руководство |
| Документация API | Описание REST API (Swagger) |
| Архитектура | Устройство платформы, развёртывание и агенты |

Выход завершает сессию на этом сервере. Открытые вкладки других приложений той же установки тоже потребуют вход заново.

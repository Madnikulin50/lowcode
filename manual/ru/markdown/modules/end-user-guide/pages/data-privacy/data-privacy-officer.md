# Офицер по защите данных

Офицер по защите данных (также называемый DPO) — это роль, назначаемая пользователю для предоставления ему достаточных разрешений на доступ ко всем полученным запросам о конфиденциальности данных.
DPO может одобрять или отклонять запросы, оставлять комментарии и планировать выполнение с помощью консоли офицера по защите данных.

## Возможности офицера по защите данных (DPO)

Офицер по защите данных имеет следующие возможности:

1. Поиск записей с полями, содержащими конфиденциальные данные, для получения требуемой информации.

1. Отклонение запроса, если он необоснован или не соответствует установленным политикам конфиденциальности.

1. Рассмотрение поданных запросов и подготовка ответов.

1. Обновление записей с конфиденциальными данными в соответствии с запросом на обновление или удаление данных.

1. Доступ к списку запросов о конфиденциальности данных и предоставление ответов.

1. Создание политики запросов о конфиденциальности для управления обработкой запросов о конфиденциальности.

## Консоль офицера по защите данных

Консоль офицера по защите данных — это пользовательский интерфейс, который позволяет DPO получать доступ к запросам о конфиденциальности от других пользователей, касающимся обработки персональных данных.

!!! important
    Консоль DPO доступна только пользователям, которым назначена роль офицера по защите данных.


С помощью консоли офицера по защите данных DPO может одобрять или отклонять запросы, предоставлять обратную связь в виде комментариев, планировать запросы на выполнение и иметь обзор модулей с конфиденциальными данными.

### Запросы о конфиденциальности

DPO имеет доступ к списку ожидающих запросов, которые необходимо одобрить.
Запросы о конфиденциальности включают исправление, экспорт и удаление.

Чтобы получить доступ к этим запросам:

На вашем инстансе LowCoooode перейдите в Консоль конфиденциальности данных, нажав на приложение btn:[Конфиденциальность].

### Модули с конфиденциальными данными

DPO имеет доступ к обзору всех модулей с полями конфиденциальных данных. 
Кроме того, он может искать модули, содержащие поля конфиденциальных данных.

# Конфиденциальность данных

Конфиденциальность данных позволяет нам указывать и описывать, как и где хранятся конфиденциальные данные на уровне модуля-поля.

Она расширяет текущие возможности хранения данных и добавляет функции, которые позволяют администраторам LowCoooode получить больше контроля над конфиденциальностью данных и управлением частными данными.
Благодаря информации из источников данных, заданных для конкретного модуля, каждая запись сможет хранить подробную информацию о владении и местонахождении конкретных данных. 

LowCoooode позволяет выбирать предопределённые политики данных или новые политики для описания цели обработки и правил на уровне поля записи.

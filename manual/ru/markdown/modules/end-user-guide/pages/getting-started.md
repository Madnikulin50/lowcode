# Начало работы

## Учётная запись

Учётную запись создаёт администратор либо, на пустой установке, первый открывший систему человек регистрируется сам. Для входа нужны адрес электронной почты и пароль. Если включён внешний вход (например, корпоративный), на странице входа будет отдельная кнопка провайдера.

Пароль меняется из меню пользователя: пункт смены пароля открывает страницу аутентификации.

## Вход

1. Откройте адрес платформы в браузере.
2. Введите почту и пароль.
3. Нажмите «Войти». «Войти и запомнить» сохраняет сессию в этом браузере.

Неверный пароль оставляет вас на странице входа. Если учётка заблокирована или срок её действия истёк, обратиться нужно к администратору: самостоятельно разблокировать её нельзя.

## Куда попадает пользователь

После входа открывается хаб приложений. Плитки ведут в Compose, администрирование и остальные модули, на которые у вас есть право. Прямая ссылка на приложение тоже работает: если сессии нет, система сначала покажет вход и затем вернёт на запрошенную страницу.

В Compose слева список страниц текущего пространства. Если пространств несколько, его выбирают в шапке. Пустое пространство без страниц — это ещё не ошибка: страницы и модули добавляет тот, кто настраивает приложение.

# Записи

В Compose данные лежат в модулях, а смотрят их через страницы. Страница собирается из блоков: список записей, форма, график, текст, вложения.

## Список

Список показывает записи, которые вам разрешено видеть. Фильтр и сортировка, если они выведены на страницу, сужают этот набор и не отменяют права доступа. Пустой список значит, что записей нет либо они скрыты фильтром или правами.

Кнопка создания есть только если у роли есть право создавать записи этого модуля.

## Карточка

Открытая запись — это форма полей модуля. Обязательные поля нужно заполнить до сохранения. Поле файла принимает вложение; скачать его можно из той же карточки, если есть право на чтение.

Чужую запись нельзя открыть по прямой ссылке, если на неё нет права: сервер вернёт отказ, даже если адрес известен.

Удаление и восстановление зависят от настроек страницы и роли. Удалённая запись пропадает из обычного списка. Вернуть её может тот, у кого есть соответствующее право.

## Что пользователь не меняет сам

Схему модуля, состав страницы, права ролей и подключения к внешним базам меняют в конструкторе и в администрировании. Если на странице нет нужного поля или кнопки, это настройка пространства, а не сбой браузера.

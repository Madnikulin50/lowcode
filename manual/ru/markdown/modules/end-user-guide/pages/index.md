# Руководство пользователя

Это руководство для человека, который работает в уже настроенной платформе Lowcode: входит в систему, открывает приложения и заполняет записи. Настройка сервера, прав и схем описана в руководствах DevOps и интегратора.

После входа доступны отдельные приложения. Какие из них видны, решает администратор.

| Приложение | Для чего |
|---|---|
| Хаб | Список приложений, с которого обычно начинают |
| Compose | Рабочие пространства: страницы, списки и карточки записей |
| Администрирование | Пользователи, роли, настройки, шлюз и автоматизация |
| Процессы | Редактор workflow |
| Отчёты | Конструктор отчётов |
| Поиск | Поиск по проиндексированным данным, если он включён |
| Конфиденциальность | Запросы субъекта данных |

Пространства вроде CRM или управления обращениями не встроены в пустую установку. Они появляются в Compose, только если их опубликовал интегратор. Описание таких пространств — в разделах ниже как примеры, а не как обязательные экраны.

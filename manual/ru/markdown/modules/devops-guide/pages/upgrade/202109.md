# Обновление до 2021.9

## Изменения в Docker-образах

LowCoooode изменил структуру Docker-образов начиная с версии 2021.9.

!!! important
    Если до версии `2021.9` вы использовали `lowcode/lowcode-server` для запуска серверных и веб-приложений, вы должны перейти на `lowcode/lowcode`.


Docker-образ `lowcode/lowcode-server` в версии `2021.9` следует использовать только в качестве сервера приложений.

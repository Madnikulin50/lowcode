# Обновление до 2023.3

## После обновления

LowCoooode `2023.3` вводит новый ресурс — `lowcode:compose:page-layout`.
Как и большинство других ресурсов, он вводит новые правила RBAC.

Пересмотрите настройки вашей модели безопасности и скорректируйте правила RBAC с учётом нового ресурса.

!!! caution
    Если конкретная роль не имеет доступа на чтение к конкретному макету страницы, этот макет не будет отображаться, и некоторые страницы могут выглядеть пустыми (из-за отсутствия доступных макетов страниц).

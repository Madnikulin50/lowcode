# Контроль доступа

LowCoooode определяет три особых типа ролей, которые необходимо зарегистрировать в файле `.env`.

.Типы ролей:
- Bypass: `RBAC*BYPASS*ROLES`; по умолчанию `super-admin`.
Роли Bypass не могут присутствовать ни в одном из других списков.
- Authenticated: `RBAC*AUTHENTICATED*ROLES`; по умолчанию `authenticated`.
Роли Authenticated не могут присутствовать ни в одном из других списков.
- Anonymous: `RBAC*ANONYMOUS*ROLES`; по умолчанию `anonymous`.

Переменные `.env` принимают разделённый пробелами список хендлов ролей.

!!! caution
    LowCoooode откажется запускаться, если конфигурация типов ролей недействительна или роли не существуют.

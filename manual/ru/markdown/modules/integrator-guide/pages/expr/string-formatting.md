# String Formatting

## `%v`

Description::
    Возвращает необработанное значение.
Example::
    `format("%v", "test")` результат: "test"

## `%t`

Description::
    Возвращает логическое значение как true/false.
Example::
    `format("%t", true)` результат: "true"

## `%b`

Description::
    Возвращает число в системе счисления по основанию 2 (в двоичном формате).
Example::
    `format("%b", 10)` результат: "1010"

## `%d`

Description::
    Возвращает число в системе счисления по основанию 10.
Example::
    `format("%d", 10)` результат: "10"

## `%o`

Description::
    Возвращает число в системе счисления по основанию 8.
Example::
    `format("%o", 10)` результат: "12"

## `%O`

Description::
    Возвращает число в системе счисления по основанию 8 с префиксом 0o.
Example::
    `format("%O", 10)` результат: "0o12"

## `%x`

Description::
    Возвращает число в системе счисления по основанию 16; строчные a-f.
Example::
    `format("%x", 10)` результат: "a"

## `%X`

Description::
    Возвращает число в системе счисления по основанию 16; заглавные A-F.
Example::
    `format("%X", 10)` результат: "A"

## `%b`

Description::
    Возвращает число с плавающей точкой в экспоненциальной записи с двоичным показателем.
Example::
    `format("%b", 10.11)` результат: "5691424029089464p-49"

## `%e`

Description::
    Возвращает число с плавающей точкой в экспоненциальной записи; строчная e.
Example::
    `format("%e", 10.11)` результат: "1.011000e+01"

## `%E`

Description::
    Возвращает число с плавающей точкой в экспоненциальной записи; заглавная E.
Example::
    `format("%E", 10.11)` результат: "1.011000E+01"

## `%f`

Description::
    Возвращает число с плавающей точкой с десятичной точкой.
Example::
    `format("%f", 10.11)` результат: "10.110000"

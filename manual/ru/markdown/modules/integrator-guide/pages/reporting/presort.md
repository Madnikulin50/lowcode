# Предсортировка

Предсортировка позволяет задать сортировку по умолчанию, которую источник данных должен применять к выходным данным.

.На скриншоте показан пользовательский интерфейс предсортировки.
![](reporter/presort.png)

Первое поле ввода определяет столбец для использования в выражении сортировки.

Второе поле ввода определяет направление сортировки: по возрастанию (сначала старые) или по убыванию (сначала новые).

При определении нескольких выражений сортировки строки сначала сортируются по первому выражению, и только строки с одинаковым значением в данном столбце сортируются по следующему выражению.

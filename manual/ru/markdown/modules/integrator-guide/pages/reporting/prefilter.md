# Предустановленные фильтры

Предустановленный фильтр позволяет определить начальную фильтрацию, которая должна быть применена к источнику данных перед возвратом каких-либо данных.

Предустановленный фильтр может быть предоставлен либо как конфигурация с использованием [default,режима по умолчанию](#default,режима по умолчанию), либо как выражение с использованием [expression,режима выражений](#expression,режима выражений).

Режим можно переключать с помощью иконки "filter" рядом с выражением.


<a id="default"></a>
## Режим по умолчанию

Режим по умолчанию позволяет передать предустановленный фильтр в виде конфигурации.

.Скриншот иллюстрирует пользовательский интерфейс предустановленного фильтра с включенным режимом по умолчанию.
![](reporter/prefilter-default.png)

Первый ввод определяет, какая колонка должна участвовать в фильтрации.

Второй ввод определяет оператор сравнения для использования.

!!! important
    Разные типы колонок могут определять разные операторы сравнения.


Третий ввод определяет значение, которое должно быть проверено относительно колонки с использованием указанного оператора сравнения.

<a id="expression"></a>
## Режим выражений

Режим выражений позволяет передать предустановленный фильтр в виде выражения, что позволяет охватить более сложные случаи.

.Скриншот иллюстрирует пользовательский интерфейс предустановленного фильтра с включенным режимом выражений.
![](reporter/prefilter-expression.png)

Обратитесь к [справочнику по выражениям](modules/integrator-guide/pages/reporting/reporting/expr-reference.md) для получения более подробной информации о написании выражений.

Пример выражения для возврата строк, где колонка `Foo` больше или равна `10`: `Foo >= 10`

Пример выражения для возврата строк, где колонка `Foo` равна строке `Foo = 'Bar'`

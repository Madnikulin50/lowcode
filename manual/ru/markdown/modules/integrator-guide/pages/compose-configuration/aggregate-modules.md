# Модуль-агрегат

Модуль типа **Агрегат** не хранит собственные записи, а описывает источник данных как цепочку шагов (аналогично датасорсам в Reporter) и отдаёт его в виде записей.

В отличие от базового модуля, для агрегата недоступна настройка DAL и системных полей, а в настройках появляется вкладка **Aggregate** (источник данных).

## Создание модуля-агрегата

1. Создайте модуль как обычно (menu:Модули[] → btn:[Создать]).
2. В поле **Тип** выберите **Aggregate**.
3. Перейдите на вкладку **Aggregate** и нажмите btn:[+], чтобы добавить шаг источника данных.

## Шаги источника данных

Цепочка состоит из последовательных шагов; каждый следующий шаг может использовать результат предыдущего.

- **Load** — загрузка данных из ресурса, например из записей Compose или из другого модуля-агрегата,
- **Link** — связывание двух источников по уникальной колонке (например, по полю-селектору записи Compose); для каждой строки локального источника создаётся собственный набор данных,
- **Join** — объединение двух источников по уникальной колонке в единый набор строк (в отличие от Link, результат — один общий набор),
- **Aggregate** — агрегация данных из Load-источника: группировка по значениям колонок и вычисление агрегатов (например, количество записей с одинаковым статусом).

### Группировка и агрегаты

Для шага **Aggregate** задаются:

- **Источник** — имя источника, из которого берутся данные (другие шаги цепочки),
- **Группировка (Group by)** — список ключей группировки; для каждого задаются имя, подпись и выражение,
- **Агрегаты (Aggregate)** — список вычисляемых колонок; для каждой задаются имя, подпись и выражение.

Шаг **Load** в качестве источника может указывать другой модуль-агрегат: сервер разрешает такие ссылки рекурсивно (с защитой от циклических ссылок), что позволяет строить агрегаты поверх агрегатов.

## Предпросмотр данных

Кнопка btn:[Preview] выполняет цепочку шагов из текущей (ещё не сохранённой) конфигурации и показывает первые 20 строк результата в таблице.
Это удобно для проверки шагов перед сохранением модуля.

!!! note
    Предпросмотр учитывает только шаги, описанные в конфигурации, и выполняется без сохранения модуля.

## Использование данных

Записи модуля-агрегата доступны как обычные записи Compose: они используются блоками страниц (списки записей, диаграммы и отчёты), а также могут быть источником для других агрегатов и отчётов Reporter.

# Поиск по страницам (Pages RAG)

Раздел menu:Pages RAG[] в административном разделе пространства имён управляет индексацией содержимого страниц для семантического поиска (Retrieval-Augmented Generation).

## Индексирование

Чтобы проиндексировать страницы пространства имён, нажмите кнопку btn:[Re-index] вверху списка.
Во время индексации отображается прогресс: количество обработанных страниц, текущая страница и полоса выполнения.
По завершении индексации выводится сообщение об успехе.

Каждая страница нарезается на фрагменты (chunks): по одному фрагменту на блок страницы.

## Список фрагментов

Список показывает все проиндексированные фрагменты с колонками:

- **Страница** — заголовок страницы,
- **Блок** — тип блока (например, record list, rich text) и заголовок блока,
- **Текст** — текст фрагмента,
- **Индекс** — порядковый номер фрагмента.

Доступны поиск по тексту, сортировка по странице и пагинация.

## Какое содержимое попадает в индекс

- Текстовое содержимое блоков страницы: заголовки, описания, тело (для текстовых блоков), подписи полей и тексты кнопок.
- Переводы страниц и блоков (если включён перевод ресурсов): для каждого языка, кроме языка по умолчанию, добавляется секция `Translations` с переведённым текстом.

### Блоки, привязанные к записям

Блоки, которые зависят от конкретной записи (например, списки записей с фильтром по `${recordID}`), в индекс **не** включаются:
они не имеют фиксированного содержимого, так как отображают данные выбранной записи.

!!! important
    После изменения страниц или переводов повторно запустите btn:[Re-index], чтобы обновить индекс.

# Фильтрация записей по вложенным полям
:page-noindex: true

LowCoooode не поддерживает нативно фильтрацию по значениям из ссылочных значений, таких как записи и пользователи.

Рассмотрим пример, в котором у нас есть два модуля: `user` и `package`, где каждый `user` может иметь `package`.
Мы хотим найти только тех пользователей, у которых есть конкретный пакет.

Вы можете использовать один из следующих обходных путей.

## Клонирование дочерних полей в родительский

Расширьте модуль `user`, добавив новое поле, например `filter*_package*name`.
Вы можете добавить дополнительные поля, если хотите использовать несколько полей.

Определите [автоматизацию](modules/integrator-guide/pages/compose-configuration/examples/automation/index.md) с триггером before create/update для модуля `user`.

Автоматизация получает связанный пакет рассматриваемого пользователя и заполняет вновь созданное поле `filter*_package*name` значением поля `name` из соответствующей записи `package`.

При поиске пользователей обращайтесь к полю `filter*_package*name`.

## Выполнение нескольких запросов

!!! important
    Эта опция применима только в том случае, если вы ищете записи за пределами существующих веб-приложений.


Вместо выполнения одного запроса вы можете выполнить несколько запросов.

Сначала получите записи `package` на основе какого-либо запроса.

.Ответ будет выглядеть примерно так:
```json
```
[{
  "recordID": "1"
},
{
  "recordID": "2"
}]

Затем получите записи `user`, где запрос ограничивает пользователей только записями, полученными в предыдущем запросе.

.Для примера запрос будет выглядеть так:
```
```
`package='1' OR package='2'`

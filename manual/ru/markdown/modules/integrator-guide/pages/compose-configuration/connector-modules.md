# Модуль-коннектор

Модуль типа **Connector** читает записи напрямую из внешнего источника данных (REST API, база данных, GraphQL, Elasticsearch) вместо хранения их в DAL Compose.
Записи загружаются «на лету» при каждом обращении к модулю (списки записей, отчёты, диаграммы).

## Создание модуля-коннектора

1. Создайте модуль как обычно (menu:Модули[] → btn:[Создать]).
2. В поле **Тип** выберите **Connector**.
3. В настройках модуля откройте вкладку **Data Connector**.

## Тип источника

В списке **Тип** доступны:

- **REST API** — HTTP-запрос к REST-сервису,
- **GraphQL** — GraphQL-запрос,
- **Elasticsearch** — поисковый запрос к Elasticsearch,
- **MongoDB**, **Kafka**, **Redis**, **gRPC** — интерфейс доступен, подключение находится в разработке,
- **БД** — SQL-запрос к базе данных (PostgreSQL, MySQL, SQLite, MS SQL Server).

Кнопка btn:[Test Connection] проверяет соединение с источником и показывает результат ✓/✗ рядом с кнопкой.

## Настройка REST API

- **URL** — адрес конечной точки,
- **Метод** — GET, POST или PUT,
- **Заголовки** — пары имя/значение (например, для авторизации),
- **Тело** — JSON, отправляемый в теле запроса (для POST/PUT),
- **Путь к данным** — JSONPath-путь до массива записей в ответе (по умолчанию — весь ответ),
- **Параметры пагинации** — имена query-параметров для `limit`, `offset` и `page`.

## Настройка GraphQL

- **URL** — адрес GraphQL-эндпоинта,
- **Запрос** — GraphQL-query,
- **Путь к данным** — путь до массива записей в ответе.

## Настройка Elasticsearch

- **URL** — адрес кластера,
- **Индекс** — имя индекса,
- **Запрос** — тело поискового запроса,
- **Параметр лимита** — имя параметра размера выборки (по умолчанию `size`).

## Настройка БД

- **Драйвер** — PostgreSQL, MySQL, SQLite или MS SQL Server,
- **Строка подключения** — DSN базы данных; если не указана, используется база данных инстанса Compose,
- **Запрос** — SQL-запрос, возвращающий колонки, которые станут записями.

## Сопоставление полей

В разделе **Field mapping** задаётся соответствие между полями модуля и ключами данных источника:

- **Поле модуля** — поле модуля Compose,
- **Ключ источника** — ключ в данных, возвращаемых источником.

Если для поля модуля сопоставление не задано, используется ключ источника с тем же именем.
Сопоставленные значения подставляются в записи модуля при чтении из источника.

!!! important
    Записи модуля-коннектора не хранятся в базе данных Compose: изменения в источнике сразу отражаются в записях, а создание и удаление записей в модуле-коннекторе недоступно.

# ETL-задания

ETL-задания загружают данные из внешних источников в модули Compose.
Раздел menu:ETL[] доступен в административном разделе пространства имён.

## Список заданий

Список показывает имя, тип источника, состояние, дату последнего запуска и действия для каждого задания:

- btn:[play] — запустить задание вручную,
- btn:[pen] — редактировать задание,
- btn:[trash] — удалить задание.

Новое задание создаётся кнопкой btn:[Создать] вверху списка.

## Редактирование задания

Форма задания содержит:

- **Имя** — произвольное название задания,
- **Источник** — тип источника данных: `rest` (HTTP API), `mcp` (Model Context Protocol) или `smb` (SMB-ресурс),
- **Конфигурация источника** — параметры подключения к источнику в виде текста (JSON),
- **Расписание** — cron-выражение для периодического запуска,
- **Включено** — флажок активации задания.

Кнопка btn:[Сохранить] создаёт или обновляет задание и возвращает к списку.

## Примеры списков записей

<a id="record-list-sample-filtering"></a>
### Фильтрация

!!! tip
    Предустановленная фильтрация списка записей поддерживает *интерполяцию значений*, которая *относится к содержимому*; например, к записи.
    
    .Доступные переменные:
    * **record**: текущая запись (когда доступна)
    * **recordID**: recordID текущей записи (когда доступен)
    * **ownerID**: владелец текущей записи (когда доступен)
    * **userID**: userID текущего пользователя


Показывать только записи, созданные в этом году::
    `YEAR(created_at) = YEAR()`.

Показывать только записи, связанные с просматриваемой записью::
    `related_contact = $\{recordID\}`.

Показывать только активные контакты::
    `is_active = '1'`.

Показывать упущенные сделки::
    `status = 'closed/lost'`.

<a id="record-list-sample-sorting"></a>
### Сортировка

Сортировать по последним::
    `created_at DESC`.

Сортировать по последним и этапу сделки::
    `created_at DESC, stage DESC`.

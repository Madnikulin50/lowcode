## Примеры блока страницы метрики

Разделить результат на 1000, чтобы показать стоимость в тысячах::
  `v / 1000`

Округлить результат, чтобы убрать десятичные знаки::
  `Math.round(v)`

Округлить результат, чтобы убрать десятичные знаки (округление в большую сторону)::
  `Math.ceil(v)`

Округлить результат, чтобы убрать десятичные знаки (округление в меньшую сторону)::
  `Math.floor(v)`

Округлить результат до двух десятичных знаков::
  `Math.round(v * 100) / 100`

!!! important
    Выражения используют *стандартный синтаксис JavaScript*, поэтому вы можете использовать любое стандартное выражение JavaScript.


!!! tip
    Вы можете указать округление с помощью форматирования значения.

# Цепочки правил

Цепочки правил позволяют визуально описывать бизнес-логику как граф узлов, соединённых рёбрами с условиями.
В отличие от [рабочих процессов](modules/integrator-guide/compose-configuration/workflows.md), которые выполняются сервером автоматизации, цепочки правил интерпретируются правилом-rules в контексте пространства имён и используются для задач, требующих детерминированного выполнения набора правил.

## Доступ к разделу

Раздел menu:Цепочки правил[] доступен в административном разделе пространства имён (sidebar пространства имён) и содержит список существующих цепочек.

Чтобы создать новую цепочку, нажмите кнопку btn:[Создать цепочку] вверху списка.

## Редактирование цепочки

Редактор цепочки открывается в двух режимах, переключаемых кнопками btn:[Visual] (граф) и btn:[Form] (форма) в шапке редактора.

### Форма

Режим btn:[Form] позволяет редактировать:

- **Имя** и **описание** цепочки,
- **Начальный узел** (entry node) — узел, с которого начинается выполнение,
- **Узлы** — список узлов графа; для каждого узла задаются:
  - метка,
  - тип (типы узлов загружаются с сервера и сопровождаются описанием и JSON-схемой конфигурации),
  - конфигурация в виде JSON-текста.
- **Рёбра (соединения)** — связи между узлами; для каждого ребра задаются:
  - начальный узел (`from`),
  - конечный узел (`to`),
  - подпись и условие выполнения.

### Визуальный режим

Режим btn:[Visual] отображает цепочку как граф: узлы — прямоугольники с метками, рёбра — стрелки с условиями.
Граф удобен для обзора структуры цепочки целиком.

## Тестирование

Кнопка btn:[Тест] в шапке редактора открывает модальное окно тестирования.
Тест принимает JSON-вход (входные данные для цепочки), выполняет цепочку и показывает результат выполнения.
При создании новой цепочки перед тестом она автоматически сохраняется.

## Сохранение

Кнопки внизу редактора:

- btn:[Сохранить] — сохранить изменения,
- btn:[Сохранить и закрыть] — сохранить и вернуться к списку,
- btn:[Сохранить копию] — сохранить копию текущей цепочки с суффиксом `(copy)` в имени,
- btn:[Удалить] — удалить цепочку.

!!! note
    Изменения узлов и рёбер сохраняются сервером: узел и ребро обновляются при каждом сохранении цепочки.

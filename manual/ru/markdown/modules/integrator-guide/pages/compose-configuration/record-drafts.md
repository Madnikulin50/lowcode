# Черновики записей

Пока пользователь заполняет форму записи, LowCoooode сохраняет черновик: его можно открыть позже из панели черновиков (она включается настройкой верхней панели).

Черновики хранятся **на сервере** и привязаны к пользователю, поэтому они доступны в любом браузере и на любом устройстве. Копия остаётся и в браузере: если сервер недоступен, черновики продолжают работать локально и отправляются на сервер при следующей синхронизации. Если копии отличаются, побеждает более свежая.

Правила:

- черновик видит и меняет только его автор;
- сохранить черновик можно, только если у пользователя есть право, которое нужно и для самой правки: обновление существующей записи или создание записей в модуле;
- у пользователя хранится до 200 черновиков (самые давно обновлённые удаляются первыми), размер одного — до 1 МБ;
- черновик — это только данные: применение черновика — обычное сохранение записи, со всеми проверками.

REST API: `GET /record-drafts`, `PUT /record-drafts/{changeID}`, `DELETE /record-drafts/{changeID}`, `DELETE /record-drafts`.

# Обнаружение дубликатов

LowCoooode с помощью функции обнаружения дубликатов помогает поддерживать чистые и точные данные, предотвращая дублирование записей.
Это достигается с помощью правил, применяющих критерий, определяющий, насколько близко поле новой или изменённой записи совпадает с тем же полем существующей записи.

Пользовательский интерфейс отображает предупреждение или сообщение об ошибке, чтобы предупредить пользователя о существовании записи с идентичными значениями полей в модуле, тем самым предотвращая создание дубликатов.

.Преимущества использования обнаружения дубликатов LowCoooode:
- повышение точности и эффективности данных,
- улучшение эффективного описания записей,
- поддержание качества данных,
- оптимизация хранения данных.

## Правила обнаружения дубликатов

Функция обнаружения дубликатов включается с помощью валидационных правил обнаружения дубликатов на модуле.
Правила гарантируют, что при создании или изменении записи не записываются дублирующиеся значения, обеспечивая отсутствие одинаковых значений в назначенных полях.

Проверку обнаружения дубликатов можно настроить с помощью двух правил:

[cols="1s,5a"]
|===
| [#strict-duplicate-validation]#[strict-duplicate-validation,Strict duplicate validation rule](#strict-duplicate-validation,Strict duplicate validation rule)#
|
Это правило гарантирует, что запись не будет сохранена, когда в выбранных полях любой существующей записи этого модуля обнаружено дублирующееся значение. 

При применении правила строгой проверки дублирующихся значений в правом нижнем углу экрана появится всплывающее сообщение об ошибке, указывающее на существование записи с идентичными значениями..

## Включение правил проверки обнаружения дубликатов

Правила проверки могут быть включены при создании новых модулей или при существующих модулях.

1. Перейдите в ваше пространство имён Low Code.
1. Выберите существующий модуль или создайте новый модуль.
1. На указанном модуле перейдите на вкладку btn:[validation].

[annotation,role="data-zoomable"]
{
  "image": {
    "rel": "duplication-detection/duplicate-detection-validation.png",
    "alias": "duplicate-detection-validation",
    "w": 1920,
    "h": 1080
  },
  "view": {},
  "annotations": [{
    "kind": "box",
    "x": 645,
    "y": 124,
    "w": 90,
    "h": 28
  }]
}

Есть два раздела, содержащие два правила проверки: строгую проверку дублирующихся значений и мягкую проверку дублирующихся значений.
Каждое правило проверки значений состоит из двух колонок: **Available fields** слева и **Selected fields** справа.

!!! note
    На одном поле записи одновременно может применяться только одно правило проверки обнаружения дубликатов.


Выберите поле из списка доступных полей, нажав на него.

Когда поле выбрано, оно перемещается в колонку выбранных полей, чтобы указать, что правило проверки было применено.

Вы можете снять правило проверки с поля записи, отменив его выбор, и оно будет перемещено обратно в колонку доступных полей.

# Макеты страниц

Макеты страниц позволяют динамически изменять содержимое страницы в зависимости от того, кто и откуда что просматривает.

LowCoooode предоставляет гибкий механизм определения того, какие макеты доступны, когда какой из них показывается и как они взаимодействуют друг с другом.
Вся система и их взаимодействие определяются с помощью простых выражений, ограничений и действий.

.Примеры вариантов использования:
- Онбординг пользователя через несколько страниц, где каждая страница фокусируется на одном фрагменте информации, таком как контактные данные, платёжные данные и способы оплаты.
- Отображение разного объёма данных в зависимости от роли или типа устройства.

!!! note
    .Планируемые улучшения функций:
    * расширение поддерживаемого набора действий,
    * предоставление пользователям возможности _форкать_ предопределённые макеты и создавать личные,
    * обеспечение взаимодействий в рамках нескольких разных страниц; в настоящее время _сеанс макета_ существует, пока вы находитесь на конкретной странице.

## Логика оценки отображения

Когда пользователь переходит на страницу, менеджеру макетов страниц необходимо определить, какой макет страницы должен быть показан.

.Менеджер макетов использует следующую логику для определения того, какой макет страницы показать:
1. Отфильтруйте макеты страниц, недоступные для набора ролей пользователя,
1. отфильтруйте макеты страниц, у которых выражение видимости возвращает `false`,
1. если оставшийся набор макетов **не пуст**, используйте первый макет,
1. если оставшийся набор макетов **пуст**, используйте первый макет без выражения,
1. если ни один макет страницы не соответствует этому процессу, пользователь перенаправляется туда, откуда он пришёл.

## Условия видимости

Условия видимости — это выражения, которые определяют, может ли макет страницы быть показан пользователю.
Макет страницы может быть показан, если условие видимости возвращает истинное значение (`true` или любое другое значение, которое JavaScript считает истинным).

Обратитесь к [странице выражений](modules/integrator-guide/pages/compose-configuration/expr/index.md) за подробностями о синтаксисе.

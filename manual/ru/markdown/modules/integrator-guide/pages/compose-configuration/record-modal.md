# Открытие записей в модальных окнах

Блоки страницы списка записей, календаря и записи имеют опцию открытия записей в модальном окне.
По умолчанию записи открываются на новой странице.
При включении эта опция позволяет пользователям просматривать конкретные записи, оставаясь на исходной странице.

## Настройка опции

Чтобы включить опцию открытия записей в модальном окне, перейдите в конструктор страниц, выберите блок списка записей и перейдите на его вкладку record list.
Прокрутите вниз до раздела Records, и вы найдёте эту опцию в выпадающем списке "On record click".

Выберите опцию "Open record in a modal".
Теперь, когда вы перейдёте на публичную страницу, отображающую список записей, и нажмёте на любую запись в списке, она откроется внутри модального окна.

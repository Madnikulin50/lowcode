# LowCoooode Studio

LowCoooode Studio позволяет пользователям настраивать стиль веб-приложений LowCoooode в соответствии со своими предпочтениями. 

!!! important
    Для корректной работы LowCoooode Studio необходимо [установить dart-sass binaries](modules/devops-guide/pages/installing-sass/index.md) в вашей системе, а
    переменная окружения `HTTP_WEBAPP_ENABLED` должна быть установлена в `true`.


## Настройка веб-приложений LowCoooode

Существует два способа настройки стиля ваших веб-приложений LowCoooode:

### Брендинг

В области администрирования перейдите в раздел брендинга menu:User Interface[Settings].

### Редактор пользовательского CSS

В области администрирования перейдите в раздел Custom CSS меню:User Interface[Settings].

!!! note
    Редактор пользовательского CSS поддерживает синтаксис как SASS, так и CSS, что позволяет настраивать стиль ваших веб-приложений LowCoooode, используя предпочитаемый язык таблиц стилей.

В этом разделе вы можете добавить код таблицы стилей, который конкретно нацелен на ваши веб-приложения.
Затем просто нажмите кнопку btn:[Submit], чтобы сохранить ваши изменения.
Это действие сохранит ваши изменения и автоматически обновит ваше веб-приложение с обновлённым стилем.

!!! caution
    Обратите внимание, что код таблицы стилей из редактора пользовательского CSS имеет приоритет над конфигурацией переменных раздела брендинга.

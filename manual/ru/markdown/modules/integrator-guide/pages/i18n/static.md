# Статические переводы

**Статический перевод** — это любой фрагмент контента, определённый на системном уровне, который нельзя изменить ни при установке системы, ни в процессе конфигурации.

Статические переводы — это подписи кнопок, системные заголовки страниц и сообщения об ошибках.

Обратитесь к [переводам ресурсов](modules/integrator-guide/pages/i18n/i18n/resource.md), чтобы узнать, как переводить настраиваемый контент.

## Включение языков

Список включённых языков определяется переменной окружения `LOCALE_LANGUAGES`.
Используйте один код языка или разделённый запятыми список кодов языков.

.Пример конфигурации, использующей английский, немецкий и итальянский языки:
```
```
LOCALE_LANGUAGES="en,de,it"

## Изменение статических переводов

### Форк репозитория lowcode-locale

Репозиторий [lowcode-locale](https://github.com/lowcode/lowcode-locale) предоставляет централизованное хранение всех переводов, используемых LowCoooode.

Вы можете использовать этот репозиторий как базу при определении дополнительных языков или изменении существующих переводов.

### Изменение переводов

Все переводы находятся в каталоге `src` репозитория lowcode-locale.
Переводы сгруппированы по **языку** и **репозиторию**, в котором они используются.

!!! caution
    Язык должен быть определён в конфигурации сервера LowCoooode, чтобы он был доступен.
    Обратитесь к [руководству DevOps](modules/devops-guide/pages/i18n/index.md) за подробностями.


Обратитесь к разделу [translation-files,изменение файлов переводов](#translation-files,изменение файлов переводов) за подробностями о том, как должны быть структурированы файлы ресурсов.

Обратитесь к разделу [languages,поддержка новых языков](#languages,поддержка новых языков) за подробностями о том, как определять дополнительные языки.

### Развёртывание изменённых переводов

Загрузите изменённые файлы переводов на ваш сервер LowCoooode.
Обратитесь к [руководству DevOps](modules/devops-guide/pages/i18n/index.md) за подробностями.

## Изменение файлов переводов

.Вот как выглядит структура файлов репозитория lowcode-locale:
```
```
📁 src
  📁 <language tag> <1>
    📁 <lowcode repository> <2>
      📄 <locale namespace file>.yaml <3>
<1> Каталог должен быть назван с использованием языкового тега содержимого.
Языковой тег должен соответствовать стандарту [BCP-47](https://en.wikipedia.org/wiki/IETF*language*tag).
<2> Каталог должен быть назван так же, как репозиторий, в котором он будет использоваться.
Например; переводы, используемые LowCoooode Low Code, названы как `lowcode-webapp-compose`.
<3> Файл содержит серию переводов, сгруппированных в пространстве имён локалей.

!!! caution
    Пространства имён локалей — это *не то же самое*, что пространства имён LowCoooode Low Code.
    Между ними нет никакой связи.


Пространство имён локалей инкапсулирует контент, относящийся к общей области, такой как боковое меню, уведомления, поля модулей.

!!! note
    За полным списком пространств имён локалей, используемых конкретным веб-приложением, возьмите английские переводы за образец.
    
    .Вы также можете изучить код инициализации i18n-плагина веб-приложений:
    * https://github.com/lowcode/lowcode/blob/{PAGE-VERSION}.x/client/web/compose/src/app.js[веб-приложение compose]
    * https://github.com/lowcode/lowcode/blob/{PAGE-VERSION}.x/client/web/admin/src/app.js[веб-приложение admin]
    * https://github.com/lowcode/lowcode/blob/{PAGE-VERSION}.x/client/web/one/src/app.js[веб-приложение one]
    * https://github.com/lowcode/lowcode/blob/{PAGE-VERSION}.x/client/web/workflow/src/app.js[веб-приложение workflow]
    * https://github.com/lowcode/lowcode/blob/{PAGE-VERSION}.x/client/web/reporter/src/app.js[веб-приложение reporter]


.Содержимое файла `en/lowcode-webapp-compose/chart.yaml`:

colorLabel: '{{count}} colors'

configure:
  reportsLabel: Reports

## Поддержка новых языков

.Вот как выглядит структура файлов репозитория lowcode-locale:
```
```
📁 src
  📁 <language tag> <1>
<1> Каталог должен быть назван с использованием языкового тега содержимого.
Языковой тег должен соответствовать стандарту [BCP-47](https://en.wikipedia.org/wiki/IETF*language*tag).

Чтобы поддержать совершенно новый язык, создайте новый каталог в каталоге `src`.
Например, чтобы добавить итальянские переводы, вам нужно создать каталог с именем `it` в каталоге `src`.

Языки можно определить с помощью простого языкового тега, такого как `en` и `sl`.
Если вам нужно больше конкретики, вы можете использовать региональный суффикс, такой как `en-US` и `en-UK`.
LowCoooode попытается определить язык из заголовков запроса и предоставит соответствующий перевод.

.Пример структуры файлов после добавления папки `it`:
```
```
📁 src
  📁 en <1>
  📁 it <2>
<1> Это каталог по умолчанию со всеми английскими переводами.
<2> Это вновь созданный каталог для итальянских переводов.

Внутри вновь созданного каталога создайте файл `config.yaml`.
Файл `config.yaml` определяет некоторые базовые свойства языка, такие как отображаемая подпись (свойство `name`).

Обратитесь к файлу [`schema/config.json`](https://github.com/lowcode/lowcode-locale/blob/{PAGE-VERSION}.x/src/schema/config.json) за подробностями.

.Пример содержимого файла `config.yaml`:
```yaml
```
name: English

.Пример структуры файлов после добавления файла `config.yaml`:
```
```
📁 src
  📁 en
  📁 it
    📄 config.yaml <1>
<1> Это файл конфигурации, описывающий данный язык.

После определения базовых элементов обратитесь к предопределённым английским переводам (находящимся в каталоге `/src/en`) за всеми доступными переводами.

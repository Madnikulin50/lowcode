# Интернационализация

LowCoooode позволяет полностью перевести большинство аспектов системы.
LowCoooode предоставляет два механизма, посвящённых интернационализации — [статические переводы](modules/integrator-guide/pages/i18n/i18n/static.md) и [переводы ресурсов](modules/integrator-guide/pages/i18n/i18n/resource.md).

!!! important
    Хотя вы можете определять и переводить на любой язык, некоторые специфичные для языка сценарии использования пока не полностью поддерживаются.


**Статический перевод** — это любой фрагмент контента, определённый на системном уровне, который нельзя изменить ни при установке системы, ни в процессе конфигурации.
Статические переводы — это подписи кнопок, системные заголовки страниц и сообщения об ошибках.

**Перевод ресурса** — это любой фрагмент контента LowCoooode Low Code, который определяется администратором при настройке инстанса LowCoooode.
Переводы ресурсов — это имена модулей, заголовки страниц Low Code и имена пространств имён.

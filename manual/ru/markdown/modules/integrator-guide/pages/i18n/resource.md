# Переводы ресурсов

**Перевод ресурса** — это любой фрагмент контента LowCoooode Low Code, который определяется администратором при настройке инстанса LowCoooode.

!!! note
    Переводы ресурсов отличаются от инстанса к инстансу, поэтому _стандартный_ поток статических переводов здесь не применяется.


Переводы ресурсов — это имена модулей, заголовки страниц Low Code и имена пространств имён.

Обратитесь к [статическим переводам](modules/integrator-guide/pages/i18n/i18n/static.md), чтобы узнать, как переводить статический контент.

<a id="resource-translations"></a>
## Настройка переводов ресурсов

!!! important
    Некоторые ресурсы *не поддерживают* переводы ресурсов.
    Как правило, только ресурсы, доступные конечным пользователям, поддерживают переводы ресурсов.


Пользовательский интерфейс переводов ресурсов доступен по кнопке **language** {ICON_I18N}, которую вы нажмёте при редактировании ресурса, поддерживающего эту функцию.

Чтобы включить это, задайте `LOCALE*RESOURCE*TRANSLATIONS_ENABLED=true` как переменную окружения.
Переводы ресурсов в настоящее время могут использовать только языки, определённые в переменной окружения `LOCALE_LANGUAGES`.

## Поддержка новых языков

Чтобы добавить новый язык, откройте пользовательский интерфейс редактора переводов ресурсов и нажмите кнопку btn:[add language].

Нажмите на язык, который хотите добавить, и он появится в редакторе переводов ресурсов.

!!! important
    Язык должен быть определён в `.env` перед тем, как его можно будет использовать здесь.
    Обратитесь к [руководству DevOps](modules/devops-guide/pages/i18n/index.md) о том, как зарегистрировать новые языки.

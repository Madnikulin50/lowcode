# Управление приложениями

Приложение на low-code платформе LowCoooode — это ссылка на домашнюю страницу ресурса. 
Для каждого ресурса у каждого приложения есть соответствующий эскиз, как показано на скриншоте ниже.

## Создание приложения

Чтобы создать новое приложение, войдите в свой инстанс LowCoooode и нажмите на приложение btn:[Admin Area].

## Редактирование приложения

Чтобы внести изменения в детали приложения, войдите в свой инстанс LowCoooode и нажмите на приложение btn:[Admin Area].

## Включение видимости приложения

Чтобы включить видимость приложения, найдите и отметьте флажок btn:[Listed] на странице редактирования приложения.

[annotation,role="data-zoomable"]
{
  "image": {
    "rel": "application/application-checkbox.png",
    "w": 1920,
    "h": 1080
  },
  "view": {},
  "annotations": [{
    "kind": "box",
    "x": 1146,
    "y": 568,
    "w": 102,
    "h": 18
  }]
}

Этот шаг делает приложение видимым в списке доступных приложений вашего инстанса LowCoooode, как показано на скриншоте ниже.

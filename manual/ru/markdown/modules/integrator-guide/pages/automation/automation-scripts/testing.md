# Тестирование

!!! note
    *DevNote*: приведите несколько сложных примеров с использованием Sinon и промисов.


Расширения — это, по сути, проекты Node.js с дополнительными частями, то есть расширения можно тестировать так же, как и node.js-проекты.

Вы можете использовать любую платформу и методологию тестирования.

!!! note
    Обычно мы используем https://www.chaijs.com/[Chai], https://mochajs.org/[Mocha], https://www.npmjs.com/package/nyc[Nyc] и https://sinonjs.org/[Sinon].

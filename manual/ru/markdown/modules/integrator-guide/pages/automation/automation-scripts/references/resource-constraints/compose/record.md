| record.updatedAt
| Ограничение проверяет значение по атрибуту `updatedAt` записи в формате RFC3339 (например: `2006-01-02T15:04:05Z07:00`)

| record.createdAt
| Ограничение проверяет значение по атрибуту `createdAt` записи в формате RFC3339 (например: `2006-01-02T15:04:05Z07:00`)

| record.deletedAt
| Ограничение проверяет значение по атрибуту `deletedAt` записи в формате RFC3339 (например: `2006-01-02T15:04:05Z07:00`)

| record.values.*
| Ограничение проверяет значение по значению записи.
Может использоваться любое поле, определённое модулем записи.

| channel
| Ограничение проверяет значение по названию канала.

| channel.name
| Ограничение проверяет значение по названию канала.

| channel.topic
| Ограничение проверяет значение по теме канала.

| channel.type
| Ограничение проверяет значение по типу канала.
Значение может быть `public`, `private` или `group`.

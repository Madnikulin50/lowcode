| request.remoteAddress
| Ограничение проверяет значение по удалённому адресу запроса.

| request.method
| Ограничение проверяет значение по методу запроса.
Значением может быть любой стандартный метод HTTP-запроса.

| request.path
| Ограничение проверяет значение по пути URL запроса.
Например, для `www.address.tld/some/path` потребуется `/some/path`.

| request.username
| Ограничение проверяет значение по имени пользователя базовой аутентификации запроса.

| request.password
| Ограничение проверяет значение по паролю базовой аутентификации запроса.

| request.content-type
| Ограничение проверяет значение по полю заголовка типа содержимого запроса.


| request.get.*
| Ограничение проверяет значение по get-параметрам запроса.
Это будет истинным, если совпадает ***любое*** значение в случае нескольких значений параметра запроса.

| request.post.*
| Ограничение проверяет значение по параметрам тела post-запроса.

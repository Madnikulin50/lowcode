| record.values.*

Может использоваться любое поле, определённое модулем записи.

### sink (`system:sink`)

[cols="2m,5"]
|===
|property|Description
| request.remoteAddress
| Ограничение проверяет значение по удалённому адресу запроса.

| request.method
| Ограничение проверяет значение по методу запроса.
Значением может быть любой стандартный метод HTTP-запроса.

| request.path
| Ограничение проверяет значение по пути URL запроса.
Например, для `www.address.tld/some/path` потребуется `/some/path`.

| request.username
| Ограничение проверяет значение по имени пользователя базовой аутентификации запроса.

| request.password
| Ограничение проверяет значение по паролю базовой аутентификации запроса.

| request.content-type
| Ограничение проверяет значение по полю заголовка типа содержимого запроса.


| request.get.*
| Ограничение проверяет значение по get-параметрам запроса.
Это будет истинным, если совпадает ***любое*** значение в случае нескольких значений параметра запроса.

| request.post.*
| Ограничение проверяет значение по параметрам тела post-запроса.
<!-- TODO: o a bit more descriptive? -->

| request.header.*
| Ограничение проверяет значение по параметрам заголовка запроса.
|===

### mail (`system:mail`)

[cols="2m,5"]
|===
|property|Description
| mail.header.subject
| Ограничение проверяет значение по теме письма.

| mail.header.from
| Ограничение проверяет значение по отправителю письма.
Это будет истинным, если совпадает ***любое*** значение.

| mail.header.to
| Ограничение проверяет значение по получателю письма.
Это будет истинным, если совпадает ***любое*** значение.

| mail.header.replyTo
| Ограничение проверяет значение по адресу для ответа письма.
Это будет истинным, если совпадает ***любое*** значение.

| mail.header.cc
| Ограничение проверяет значение по копии (cc) письма.
Это будет истинным, если совпадает ***любое*** значение.

| mail.header.bcc
| Ограничение проверяет значение по скрытой копии (bcc) письма.
Это будет истинным, если совпадает ***любое*** значение.
|===

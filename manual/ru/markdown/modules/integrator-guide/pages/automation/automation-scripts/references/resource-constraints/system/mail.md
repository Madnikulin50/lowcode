| mail.header.subject
| Ограничение проверяет значение по теме письма.

| mail.header.from
| Ограничение проверяет значение по отправителю письма.
Это будет истинным, если совпадает ***любое*** значение.

| mail.header.to
| Ограничение проверяет значение по получателю письма.
Это будет истинным, если совпадает ***любое*** значение.

| mail.header.replyTo
| Ограничение проверяет значение по адресу для ответа письма.
Это будет истинным, если совпадает ***любое*** значение.

| mail.header.cc
| Ограничение проверяет значение по копии (cc) письма.
Это будет истинным, если совпадает ***любое*** значение.

| mail.header.bcc
| Ограничение проверяет значение по скрытой копии (bcc) письма.
Это будет истинным, если совпадает ***любое*** значение.

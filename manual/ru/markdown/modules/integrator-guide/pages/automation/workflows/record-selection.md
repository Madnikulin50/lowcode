# Обработка выбора записей

Списки записей позволяют включить выбор записей, что даёт возможность выполнять автоматизацию над серией записей.

<a id="wf-config"></a>
## Конфигурация рабочего процесса

.Чтобы настроить рабочий процесс, поддерживающий выбор записей:
1. перейдите в приложение Workflow и создайте или отредактируйте рабочий процесс,
1. добавьте триггер с ресурсом `Compose Page` или `Compose Record`,

Рабочий процесс получает переменную области видимости `selected`, которая определяет список выбранных ID записей.
Например; переменная области видимости `selected` может содержать список `[ '1111', '2222', ..., 'nnnn' ]`.

Вы можете использовать итератор элементов, чтобы пройтись по списку выбранных записей.
Оттуда вы можете использовать функции и выражения для реализации вашей функции.

## Конфигурация Low Code

!!! important
    Убедитесь, что у вас уже есть автоматизация, которую может использовать список записей.
    Обратитесь к <<wf-config,конфигурации рабочего процесса>> за подробностями.


.Чтобы включить выбор записей:
1. перейдите в приложение Low Code и войдите в пространство имён, которое хотите редактировать,
1. перейдите в menu:Admin panel[Pages],
1. нажмите на конструктор страниц рядом со страницей, для которой хотите включить выбор записей,
1. нажмите btn:[иконку редактирования] на блоке страницы со списком записей,
1. перейдите на вкладку «список записей» и отметьте флажок «включить выбор записей».

.Чтобы привязать кнопку автоматизации к списку записей:
1. перейдите в приложение Low Code и войдите в пространство имён, которое хотите редактировать,
1. перейдите в menu:Admin panel[Pages],
1. нажмите на конструктор страниц рядом со страницей, для которой хотите включить выбор записей,
1. нажмите btn:[иконку редактирования] на блоке страницы со списком записей,
1. перейдите на вкладку «автоматизация» и выберите автоматизацию, которую хотите использовать.

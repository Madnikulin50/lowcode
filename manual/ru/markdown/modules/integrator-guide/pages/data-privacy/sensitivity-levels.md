# Уровни чувствительности

**Уровни чувствительности** предоставляют способ классификации того, какие подключения, модули и поля хранят конфиденциальную информацию.

!!! important
    В настоящее время пользовательский интерфейс допускает до 10 уровней чувствительности.


.Уровни чувствительности можно определить в трёх местах:
[cols="1s,5a"]
|===
| [#sensitivity-level-connection]#[sensitivity-level-connection,DAL-подключение](#sensitivity-level-connection,DAL-подключение)#
|
Уровень чувствительности на **DAL-подключении** определяет наивысший уровень чувствительности записи, хранящейся в данном подключении.
Уровень чувствительности подключения также определяет наивысший уровень чувствительности для нижележащих **модулей** и **полей модулей**.

Например, вы можете заставить LowCoooode сохранять все медицинские записи в выделенную зашифрованную базу данных.

По умолчанию, если уровень чувствительности не указан, данные считаются неконфиденциальными.

| [#sensitivity-level-module]#[sensitivity-level-module,Модуль Low Code](#sensitivity-level-module,Модуль Low Code)#
|
Уровень чувствительности на **модуле Low Code** определяет уровень чувствительности записей, хранящихся в данном модуле.
Уровень чувствительности модуля также определяет наивысший уровень чувствительности для нижележащих **полей модулей**.

По умолчанию, если уровень чувствительности не указан, данные считаются неконфиденциальными.

| [#sensitivity-level-module-field]#[sensitivity-level-module-field,Поле модуля Low Code](#sensitivity-level-module-field,Поле модуля Low Code)#
|
Уровень чувствительности на **поле модуля Low Code** определяет уровень чувствительности значения записи, хранящейся в данном модуле.

!!! note
    Конкретные значения записей могут быть определены как менее чувствительные, чем модуль Low Code.


По умолчанию, если уровень чувствительности не указан, данные считаются неконфиденциальными.

|===

## Настройка модулей Low Code

Чтобы настроить LowCoooode Low Code с уровнем чувствительности, откройте веб-приложение LowCoooode Low Code и перейдите в панель администрирования нужного пространства имён.
Из списка модулей нажмите на модуль, который вы хотите обновить.

!!! caution
    В случае несовместимости изменение значения уровня чувствительности в модуле сбросит уровень чувствительности, заданный на полях модуля.


Перейдите на вкладку btn:[настройки конфиденциальности] и найдите опцию «наивысший разрешённый уровень чувствительности».

# Раскрытие информации об использовании

**Раскрытие информации об использовании** предоставляет способ сообщить конечному пользователю, как его конфиденциальные данные используются в системе и в вашей организации.

!!! note
    Раскрытие информации об использовании отображается на консоли конфиденциальности, когда пользователь взаимодействует со своей конфиденциальной информацией.


.Раскрытие информации об использовании можно определить на двух уровнях:
- [usage-disclosure-module,**Раскрытие на уровне модуля**](#usage-disclosure-module,**Раскрытие на уровне модуля**) описывает, как используется вся запись,
- [usage-disclosure-field,**Раскрытие на уровне поля модуля**](#usage-disclosure-field,**Раскрытие на уровне поля модуля**) описывает, как используется конкретное значение.

<a id="usage-disclosure-module"></a>
## Раскрытие на уровне модуля

**Раскрытие на уровне модуля** описывает, как используется вся запись.
Раскрытия информации об использовании на уровне модуля идеально подходят для описания общего назначения модуля, например, данные, продаваемые рекламным провайдерам.

Чтобы установить раскрытие информации об использовании на уровне модуля, перейдите в панель администрирования вашего пространства имён Low Code и отредактируйте соответствующий модуль.
Поле ввода раскрытия информации об использовании конфиденциальных данных доступно на вкладке btn:[настройки конфиденциальности].

## Раскрытие на уровне поля

**Раскрытие на уровне поля модуля** описывает, как используется конкретное значение записи.
Раскрытия информации об использовании на уровне поля модуля идеально подходят для указания конкретных полей, которые могут быть не очевидны из общего раскрытия на уровне модуля.

Чтобы установить раскрытие информации об использовании на уровне поля модуля, перейдите в панель администрирования вашего пространства имён Low Code и отредактируйте соответствующий модуль.
Нажмите на кнопку btn:[редактировать] рядом с полем модуля, для которого вы хотите установить раскрытие.
Поле ввода раскрытия информации об использовании конфиденциальных данных доступно на вкладке btn:[конфиденциальность].

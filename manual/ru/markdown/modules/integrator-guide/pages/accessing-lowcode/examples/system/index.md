# Системный API

!!! important
    Любая операция, выполнимая через клиентское приложение, выполнима и через API; либо через один эндпоинт, либо через их комбинацию.


Системный API отвечает за основные системные ресурсы, такие как пользователи и роли.
Он также отвечает за основные операции, такие как аутентификация.

!!! tip
    Всякий раз, когда операция затрагивает систему и не является специфичной для какого-либо из наших приложений, вам, скорее всего, понадобится использовать системный API


!!! important
    Мы опускаем большую часть данных, возвращаемых этими эндпоинтами.
    Мы заменяем важные данные переменными, такими как `$JWT`, чтобы вы могли копировать и вставлять эти примеры в любое окружение.


- **Путь URL**: `/system`,
- **alias**: `$SystemAPI`,

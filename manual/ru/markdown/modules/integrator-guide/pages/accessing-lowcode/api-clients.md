# API-клиенты

LowCoooode определяет серию JavaScript API-клиентов (SDK) для работы с нашим API.

!!! tip
    При написании скриптов автоматизации API-клиенты предоставляются в [контексте выполнения](modules/integrator-guide/pages/automation/automation-scripts/index.md#execution-context).


Вы можете найти исходный код на [GitHub/lowcode/lowcode-js](https://github.com/lowcode/lowcode-js).
Пакеты NPM можно найти на [NPM/@lowcode/lowcode-js](https://www.npmjs.com/package/@lowcode/lowcode-js).

При использовании нашего пакета `lowcode-js` API-клиенты можно импортировать с помощью `import { apiClients } from '@lowcode/lowcode-js'`.

.Доступные API-клиенты LowCoooode:
- [`apiClients.System`](https://github.com/lowcode/lowcode-js/blob/2021.3.x/src/api-clients/system.ts)
- [`apiClients.Compose`](https://github.com/lowcode/lowcode-js/blob/2021.3.x/src/api-clients/compose.ts)
- [`apiClients.Automation`](https://github.com/lowcode/lowcode-js/blob/2021.3.x/src/api-clients/automation.ts)
- [`apiClients.Federation`](https://github.com/lowcode/lowcode-js/blob/2021.3.x/src/api-clients/federation.ts)

!!! note
    Пожалуйста, обратитесь к исходному коду для получения полного справочника.

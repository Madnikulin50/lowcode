# Пагинация

Когда вы выполняете операцию, поддерживающую пагинацию (например, получение записей), вы увидите объект `filter`.

.Объект `filter` содержит:
```json
```
{
  "limit": ...<1>
  "cursor": "..."<2>
  "nextPage": "..."<3>
  "prevPage": "..."<4>
}
<1> `limit` (число) задаёт максимальное количество элементов на странице.
<2> `cursor` (строка) задаёт курсор текущей страницы.
<3> `nextPage` (строка) задаёт следующую страницу (опускается, если следующей страницы нет).
<4> `prevPage` (строка) задаёт предыдущую страницу (опускается, если предыдущей страницы нет).

Когда вы хотите получить доступ к конкретной странице, вы должны указать параметр запроса `pageCursor=$PAGE_CURSOR`.
При переходе на следующую страницу `$PAGE*CURSOR` — это `filter.nextPage`; при переходе на предыдущую страницу `$PAGE*CURSOR` — это `filter.prevPage`.

.Например:
```bash
```
curl -X GET "$API*BASE/compose/namespace/$NAMESPACE*ID/module/$MODULE*ID/record/?pageCursor=$PAGE*CURSOR";

# Управление пользователями

Пользователь — это субъект, которому разрешено взаимодействовать с вашим инстансом LowCoooode.
Пользователем может быть сотрудник, которому нужно взаимодействовать с LowCoooode, или системный пользователь, который может использоваться для идентификации внешних интеграций или webhook-запросов.

Пользователю может быть назначен ряд [ролей](modules/integrator-guide/pages/security-model/security-model/roles.md), определяющих область доступа данного пользователя.

!!! important
    По соображениям конфиденциальности персональная информация скрыта по умолчанию.
    Это можно настроить, задав соответствующие правила контроля доступа либо для всех пользователей, либо для конкретного пользователя.
    
    .Чтобы изменить скрытие информации для всех пользователей:
    . Нажмите кнопку btn:[permissions] в правом верхнем углу,
    . выберите роль, для которой хотите это изменить,
    . выберите подходящий вариант доступа для «показывать данные электронной почты любого пользователя» или «показывать данные имени любого пользователя».
    
    .Чтобы изменить скрытие информации для конкретных пользователей:
    . Нажмите значок редактирования рядом с пользователем, для которого хотите это изменить,
    . нажмите кнопку btn:[permissions] в правом верхнем углу,
    . выберите роль, для которой хотите это изменить,
    . выберите подходящий вариант доступа для «показывать данные электронной почты (имя здесь)» или «показывать данные имени (имя здесь)».

## Создание пользователей

!!! important
    Разрешения можно определять только для существующих пользователей.


.Чтобы создать нового пользователя:
1. перейдите в menu:system[users],
1. нажмите кнопку btn:[new] в правом верхнем углу,
1. укажите запрашиваемые данные,
1. нажмите кнопку btn:[submit].

## Редактирование пользователей

.Чтобы отредактировать существующего пользователя:
1. перейдите в menu:system[users],
1. нажмите значок btn:[edit] рядом с пользователем, которого хотите отредактировать,
1. обновите параметры, которые хотите изменить,
1. нажмите кнопку btn:[submit].

1. нажмите значок btn:[edit] рядом с пользователем, которого хотите удалить,

## Назначение ролей

!!! caution
    Чтобы изменение членства в ролях отразилось на пользователе, ему нужно войти в систему заново.


.Чтобы назначить роль существующему пользователю:
1. перейдите в menu:system[users],
1. нажмите значок btn:[edit] рядом с пользователем, которого хотите отредактировать,
1. перейдите в раздел «членство в ролях» и назначьте подходящие роли,
1. нажмите кнопку btn:[submit].

!!! note
    Обратитесь к [модели безопасности](modules/integrator-guide/pages/security-model/security-model/index.md) за дополнительной информацией о ролях и контроле доступа.

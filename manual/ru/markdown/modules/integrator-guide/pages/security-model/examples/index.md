# Примеры выражений контекстных ролей
:page-noindex: true

[cols="2s,5a"]
|===
| Владелец ресурса
|
Назначайте эту роль, когда текущий пользователь является владельцем ресурса.

```
```
userID == ownerID

| Владелец ресурса, но не создатель
|
Назначайте эту роль, когда текущий пользователь является владельцем ресурса, но не его создателем.

```
```
userID == ownerID && userID != creatorID

| Упомянут в многозначном поле модуля
|
Назначайте эту роль, когда текущий пользователь упомянут в многозначном поле `editor` данной записи.

```
```
has(resource.values.editor, userID)

| Владелец записи с определённым состоянием записи
|
Назначайте эту роль, когда текущий пользователь является владельцем записи, а значение поля `published` равно false.

```
```
userID == ownerID && !resource.values.published

Бенчмарк выделенных таблиц тестирует оптимизированную конфигурацию, в которой поля модуля получают собственные выделенные столбцы в таблице. Вы можете применять стандартные оптимизации базы данных (например, индексирование) для лучшего соответствия вашим потребностям.
Эта конфигурация предназначена для модулей с высоким объёмом данных, так как позволяет лучше использовать индексирование и снижает накладные расходы на JSON-кодирование.

!!! note
    Этот документ следует использовать как основу для выбора наиболее подходящей конфигурации.
    Вы можете использовать сырые числа различных сценариев, чтобы сделать собственные выводы о том, насколько хорошо конкретная конфигурация подойдёт для вашего случая использования.


.Примечания к тестированию:
- Подвыборка столбцов с указанными индексами влияет как на операции CRUD, так и на операции поиска.
- Все значения указаны в миллисекундах, без учёта сетевых задержек (скрипты выполнялись непосредственно на сервере).
- В каждом сценарии использовалась выделенная таблица БД, настроенная для определения отдельного столбца для каждого поля модуля. Основная причина — повторяемость результатов.
- Записи создавались из предопределённого набора данных со случайно сгенерированными данными с помощью faker.js.
- Бенчмарки выполнялись на выделенном облачном экземпляре с минимальным количеством фоновых процессов.
- В тестах используется Postgres в качестве базы данных.

.Наблюдения по тестированию:
- Мы заметили случайные всплески максимального времени, которые не смогли объяснить. Возможно, это связано с фоновыми системными задачами или троттлингом. В идеале в будущих тестах такие аномалии стоило бы исключить или обрабатывать лучше.

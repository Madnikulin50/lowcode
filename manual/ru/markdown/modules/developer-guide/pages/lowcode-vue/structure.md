# Структура

## `/src/components`

Каталог `/src/components` содержит все общие Vue-компоненты, доступные любому веб-приложению на основе Vue.

.Примеры компонентов:
- модальное окно разрешений, используемое для управления разрешениями,
- предпросмотр файлов,
- пользовательские поля ввода, такие как DateTime и Confirmation,
- уведомления-тосты.

## `/src/corredor`

Каталог `/src/corredor` содержит специфичную для Corredor логику, такую как обработка и выполнение клиентских скриптов.

## `/src/libs`

Каталог `/src/libs` содержит общие библиотеки и утилиты, которые вы можете использовать в исходном коде `lowcode-vue`.

## `/src/mixins`

Каталог `/src/mixins` содержит общие миксины, доступные любому веб-приложению на основе Vue.

## `/src/plugins`

Каталог `/src/plugins` содержит общие плагины, доступные любому веб-приложению на основе Vue.

## `/src/store`

Каталог `/src/store` содержит общие определения и обработчики хранилища, доступные любому веб-приложению на основе Vue.

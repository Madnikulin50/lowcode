# LowCoooode Vue

Пакет [`lowcode-vue`](http://github.com/lowcode/lowcode-vue) предоставляет общую специфичную для Vue логику, которая должна быть доступна любому веб-приложению на основе Vue.

Наиболее частые варианты использования пакета `lowcode-vue` включают плагины аутентификации и клиента API.

!!! note
    Обратитесь к [Core Repos](modules/developer-guide/pages/lowcode-vue/release-cycle/core-repos.md) за подробностями о процессе выпуска.


## Настройка разработки

### Форк репозитория `lowcode-vue`

!!! caution
    Основные участники могут пропустить эту часть.


1. перейдите в репозиторий https://github.com/{GIT*REPO*GROUP}/{GIT*REPO*PREFIX}-vue
1. нажмите кнопку btn:[Fork] в правом верхнем углу и следуйте инструкциям на экране.

### Клонирование репозитория

.С помощью CLI:
1. откройте CLI
1. перейдите в вашу рабочую папку
1. выполните команду `git clone git@github.com:lowcode/lowcode-vue.git`

!!! tip
    Обратитесь к https://github.com/lowcode/lowcode-vue[репозиторию], если вы хотите использовать альтернативный метод.


### Проверка зависимостей

!!! caution
    При использовании изменённых версий `lowcode-js` обязательно свяжите его с помощью `yarn link @lowcode/lowcode-js`.


Выполните команду `yarn`, чтобы убедиться, что все пакеты присутствуют и актуальны.

См. файл `package.json` для поддерживаемых версий Node.js.

### Сборка бандла

Выполните команду `yarn build`, чтобы собрать новый бандл.
Необязательный флаг `-w` автоматически пересоберёт бандл при изменениях.

## Связывание пакета

Выполните команду `yarn link`, чтобы сделать этот пакет доступным для связывания.
Пакет можно связать, выполнив `yarn link @lowcode/lowcode-vue` там, где это необходимо.

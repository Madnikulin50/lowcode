# Структура

## `/tools`

Каталог `/tools` содержит инструменты, которые автоматизируют некоторые задачи, такие как генератор кода клиента API.
Вы должны добавить скрипт для запуска инструмента в файл `/package.json`.

## `/src/api-clients`

Каталог `/src/api-clients` содержит сгенерированные клиенты REST API.
Клиенты API генерируются инструментом `/tools/codegen` на основе определений файлов `lowcode-server/***/rest.yaml`.

Каждый клиент API должен быть предоставлен в виде отдельного класса, чтобы он мог существовать самостоятельно.

Кодогенератор запускается командой `yarn codegen:lowcode-api-client`.

## `/src/automation`

Каталог `/src/automation` содержит общий код для автоматизации, такой как определения типов.

## `/src/compose`

Каталог `/src/compose` содержит общий код для Compose, такой как определения типов.

## `/src/corredor`

Каталог `/src/corredor` содержит общий код для Corredor, такой как определения типов, утилиты разбора скриптов и вспомогательные классы Corredor.

## `/src/corredor/helpers`

Каталог `/src/corredor/helpers` содержит вспомогательные классы Corredor.
Вспомогательные классы реализуют общие операции автоматизации, такие как создание и обновление записей.

## `/src/eventbus`

Каталог `/src/eventbus` содержит клиентскую реализацию шины событий.
Шина событий обрабатывает dispatched-события и реагирует на них.

## `/src/system`

Каталог `/src/system` содержит общий код для основной системы, такой как определения типов.

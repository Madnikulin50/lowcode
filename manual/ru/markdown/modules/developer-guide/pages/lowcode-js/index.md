# LowCoooode JS

Пакет [`lowcode-js`](http://github.com/lowcode/lowcode-js) предоставляет общую логику, которая должна быть доступна любому веб-приложению или приложению Node.js.

Наиболее частые варианты использования пакета `lowcode-js` включают определения типов и сгенерированный код клиента API.

!!! note
    Обратитесь к [Core Repos](modules/developer-guide/pages/lowcode-js/release-cycle/core-repos.md) за подробностями о процессе выпуска.


## Настройка разработки

### Форк репозитория `lowcode-js`

!!! caution
    Основные участники могут пропустить эту часть.


1. перейдите в репозиторий https://github.com/{GIT*REPO*GROUP}/{GIT*REPO*PREFIX}-js
1. нажмите кнопку btn:[Fork] в правом верхнем углу и следуйте инструкциям на экране.

### Клонирование репозитория

.С помощью CLI:
1. откройте CLI
1. перейдите в вашу рабочую папку
1. выполните команду `git clone git@github.com:$YOUR*USERNAME*HERE/lowcode-js.git`

!!! tip
    Обратитесь к https://github.com/lowcode/lowcode-js[репозиторию], если вы хотите использовать альтернативный метод.


### Проверка зависимостей

Выполните команду `yarn`, чтобы убедиться, что все пакеты присутствуют и актуальны.

См. файл `package.json` для поддерживаемых версий Node.js.

### Сборка бандла

Выполните команду `yarn build`, чтобы собрать новый бандл.
Необязательный флаг `-w` автоматически пересоберёт бандл при изменениях.

## Связывание пакета

Выполните команду `yarn link`, чтобы сделать этот пакет доступным для связывания.
Пакет можно связать, выполнив `yarn link @lowcode/lowcode-js` там, где это необходимо.

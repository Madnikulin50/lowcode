# Безопасность и логирование

## Безопасность

LowCoooode Federation использует уже установленный механизм аутентификации LowCoooode, применяя **системных пользователей и JWT-токены** (далее называемые токеном).

Это позволяет нам **уменьшить потенциальные дыры в безопасности** и **использовать наш механизм контроля доступа RBAC**.

Во время [**сопряжения узлов**](modules/developer-guide/pages/lowcode-server/federation/lowcode-server/federation/node-pair.md) каждый узел создаёт **системного пользователя** с **токеном аутентификации**, который можно использовать для доступа к защищённым ресурсам узла.

!!! note
    Два токена в паре узлов не одинаковы.


**После сопряжения узлов** и создания системных пользователей мы можем **назначать роли федеративному пользователю**, дополнительно ограничивая, к каким данным узлу-назначению **разрешено обращаться**, используя механизм контроля доступа RBAC

!!! note
    Каждая запрошенная операция в федеративной сети проходит через механизм контроля доступа.


## Логирование

LowCoooode Federation логирует события (действия), произошедшие в федеративной сети, в механизме журнала действий LowCoooode.

Это **обеспечивает администрирование** и **упрощает отладку** любых потенциальных проблем конфигурации.

### События сопряжения узлов

Начало сопряжения::
    Событие логируется, когда узлы инициируют шаг сопряжения узлов.

Сбой сопряжения::
    Событие логируется, когда во время шага сопряжения происходит ошибка.

Завершение сопряжения::
    Событие логируется, когда узлы были успешно сопряжены.

### События синхронизации структур

Начало синхронизации структур::
    Событие логируется, когда узлы инициируют шаг синхронизации структур.

Сбой синхронизации структур::
    Событие логируется, когда во время шага синхронизации структур происходит ошибка.

Завершение синхронизации структур::
    Событие логируется, когда узлы успешно выполнили шаг синхронизации структур.

### События синхронизации данных

Начало синхронизации данных::
    Событие логируется, когда узлы инициируют шаг синхронизации данных.

Сбой синхронизации данных::
    Событие логируется, когда во время шага синхронизации данных происходит ошибка.

Завершение синхронизации данных::
    Событие логируется, когда узлы успешно выполнили шаг синхронизации данных.

# Глоссарий

## Сопряжение узлов

!!! important
    Прежде чем мы сопряжём два узла, мы не можем определить, какой узел является источником, а какой — назначением.
    Чтобы избежать путаницы, мы используем _узел A_ и _узел B_ при обращении к двум узлам.


URI узла::
    URI, который идентифицирует федеративный узел.

Узел A::
    Узел A — это узел, который инициализирует процесс создания федеративной сети с другим узлом (узлом B).

Узел B::
    Узел B — это узел, который хочет присоединиться к федеративной сети, инициализированной узлом A.

NodeID A::
    NodeID A — это идентификатор узла A.

NodeID B::
    NodeID B — это идентификатор узла B.

Токен A::
    Токен A — это токен аутентификации, используемый для доступа к защищённым ресурсам на узле A.

Токен B::
    Токен B — это токен аутентификации, используемый для доступа к защищённым ресурсам на узле B.

## Синхронизация узлов

Узел-источник::
    **Узел-источник** — это узел, который **делится данными** с другим узлом.
    Если узел A запрашивает данные у узла B, узел B является источником, так как он содержит данные.

Узел-назначение::
    **Узел-назначение** — это узел, который **получает данные** от узла-источника.
    Если узел A запрашивает данные у узла B, узел A является назначением, так как он получает данные.

## Федеративный узел

Статус узла::
    Статус узла определяет текущий статус федеративного узла.
    Может быть одним из следующих:

    - **pairing**: узел находится в процессе сопряжения,
    - **paired**: узлы были успешно сопряжены,
    - **failed**: узлу не удалось выполнить сопряжение.

Статус синхронизации структур::
    Статус синхронизации структур определяет текущий статус синхронизации структур федеративного узла.
    Может быть одним из следующих:

    - **syncing**: узел в настоящее время синхронизирует структуры с узла-источника,
    - **synced**: узел успешно завершил синхронизацию,
    - **failed**: произошла ошибка при синхронизации.

Статус синхронизации данных::
    Статус синхронизации данных определяет текущий статус синхронизации данных федеративного узла.
    Может быть одним из следующих:

    - **syncing**: узел в настоящее время синхронизирует данные с узла-источника,
    - **synced**: узел успешно завершил синхронизацию,
    - **failed**: произошла ошибка при синхронизации.

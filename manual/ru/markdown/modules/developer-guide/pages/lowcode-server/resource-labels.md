# Метки ресурсов

**Метка ресурса** — это простая произвольная структура **ключ-значение**, которую мы можем использовать для обогащения ресурсов.
Вы можете использовать метки для таких вещей, как категоризация, группировка ресурсов и маркировка федеративных ресурсов.

.Поддерживаемые ресурсы:
- Пользователи
- Роли
- Пространство имён Compose
- Страница Compose
- Диаграмма Compose
- Модуль Compose
- Поле модуля Compose
- Запись Compose

## Основная логика

Метки ресурсов гибки и совместимы с любым ресурсом LowCoooode.
Однако, если мы хотим, чтобы ресурс использовал метки ресурсов, он должен соответствовать интерфейсу `pkg/label.LabeledResource`.

Основная логика, работающая с централизованным хранилищем меток, реализована в выделенном пакете (`pkg/label`).
Таким образом, сервисы могут тривиально включать пакет в цикл обработки запроса.

!!! tip
    Используйте сервис system/user (`system/service/user.go`) в качестве ориентира.


.Метки ресурсов определяются простой структурой ключ-значение (`pkg/label/types.Label`):
```go
```
Label struct {
  Kind string

  ResourceID uint64

}

!!! note
    Метки ресурсов определяют простую структуру ключ-значение, чтобы упростить базовую логику управления метками.
    
    Простая структура также помогает нам не _злоупотреблять_ функцией.


## Структура метки ресурса

.Метки ресурсов определяют простую структуру `key: value`:
`key`::
    Ключ метки — это простая `string`, ограниченная 512 символами.
    Ключи уникальны для конкретных ресурсов (ресурс может иметь одно значение для данного `key`).

!!! note
    `key` должен проходить следующее регулярное выражение: `^[A-Za-z][0-9A-Za-z_\-.]\*[A-Za-z0-9]$`


`value`::
    Значение метки — это обычное значение `string` без других ограничений.

## Назначение меток

.Когда предоставлен параметр `label`, ресурс должен поддерживать следующие случаи:
- Если параметр `label` **пуст**, **удалите все метки** из данного **ресурса**.
- Если параметр `label` **не пуст**, **удалите отсутствующие** метки и **добавьте новые метки**.

Если параметр `label` **не предоставлен**, никакие изменения не выполняются.

## Получение ресурсов

.Ресурс должен поддерживать следующие случаи:
- **Фильтр существования**: соберите ресурсы, **где ключ существует**.
- **Фильтр !существования**: соберите ресурсы, **где ключ не существует**.
- **Фильтр ключ-значение**: соберите ресурсы, **где ключ существует** и **значение совпадает**.

## Контроль доступа

Контроль доступа к меткам наследуется от контроля доступа к ресурсам; метки ресурсов не добавляют никакого дополнительного контроля доступа.

.Контроль доступа:
- **Доступ на чтение** наследует операцию ресурса `read`.
- **Доступ на создание** наследует операцию ресурса `create`.
- **Доступ на обновление** наследует операцию ресурса `update`.
- **Доступ на удаление** наследует операцию ресурса `delete`.

## Примечание об удалении

В большинстве случаев LowCoooode выполняет мягкое удаление.
Для простоты реализации метки **не поддерживают** мягкое удаление.

Когда **ресурс удаляется**, связанные **метки остаются неизменными**, чтобы покрыть случаи его восстановления.

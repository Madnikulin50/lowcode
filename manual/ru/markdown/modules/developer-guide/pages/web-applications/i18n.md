# Интернационализация

LowCoooode позволяет полностью перевести большинство аспектов системы.
От пользовательского интерфейса до пользовательских конфигураций Low Code, таких как модули и их поля.

Кроме того, LowCoooode настраивает форматирование значений в зависимости от локали, например пользовательские строки дат и чисел.
Для форматирования значений используется нативный API интернационализации ECMAScript.

## Обзор структуры

### `lowcode-js/src/formatting/datetime.ts`

Файл `lowcode-js/src/formatting/datetime.ts` определяет функции, которые следует использовать при локализации временных значений, таких как даты и метки времени.

Текущая реализация определяет три функции, которые следует использовать для разных применений.

- `fullDateTime`: выводит дату и время, отформатированные с учётом локали, без секунд.
- `date`: выводит дату, отформатированную с учётом локали, без времени.
- `time`: выводит время, отформатированное с учётом локали.

### `lowcode-js/src/formatting/number.ts`

Файл `lowcode-js/src/formatting/number.ts` определяет функции, которые следует использовать при локализации числовых значений.

## Использование

.Пример варианта использования:
```js
```
import { fmt } from '@lowcode/lowcode-js'


fmt.fullDateTime(sampleDate, optionalDateTimeFormat)
fmt.date(sampleDate, optionalDateTimeFormat)
fmt.time(sampleTime, optionalDateTimeFormat)

Если вы хотите проверить вывод для разных локалей, вам нужно изменить локаль в настройках браузера.
LowCoooode отреагирует на изменение и будет использовать вновь назначенную локаль.

## Изменение форматирования

Чтобы изменить форматирование по умолчанию, передайте объект [`Intl.DateTimeFormat`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat) последним аргументом вызова функции.

.Пример переопределения формата по умолчанию:
```js
```
fmt.fullDateTime(sampleDate, {
  day: "numeric",
  month: "numeric",
  year: "numeric",
  hour: "numeric",
  minute: "numeric",
})

!!! note
    Refer to the https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat[`Intl.DateTimeFormat documentation`] for details.


### Справочник пользовательских форматов

.`dateStyle`:
- `full`
- `long`
- `medium`
- `short`

.`timeStyle`:
- `full`
- `long`
- `medium`
- `short`

.`year`:
- `numeric` (пример вывода: `2012`)
- `2-digit` (пример вывода: `12`)

.`month`:
- `numeric` (пример вывода: `2`)
- `2-digit` (пример вывода: `02`)
- `long` (пример вывода: `March`)
- `short` (пример вывода: `Mar`)
- `narrow` (пример вывода: `M`)

.`day`:
- `numeric` (пример вывода: `1`)
- `2-digit` (пример вывода: `01`)

.`minute`:
- `numeric`
- `2-digit`

.`second`:
- `numeric`
- `2-digit`

## Поддержка RTL

LowCoooode обеспечивает поддержку направления справа налево для следующих языков:

- арабский
- иврит
- пушту
- персидский
- урду
- синдхи

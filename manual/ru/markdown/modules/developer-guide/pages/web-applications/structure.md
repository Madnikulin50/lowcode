# Структура

## `/public`

Каталог `/public` содержит ресурсы, которые должны быть доступны веб-приложению как есть, например файл конфигурации и логотип.

## `/src`

Каталог `/src` содержит основную логику веб-приложения.
Ядро инициализирует приложение Vue, регистрирует глобальные компоненты, плагины, миксины и хранилище.

## `/src/components`

Каталог `/src/components` содержит все компоненты, используемые во всём веб-приложении или отдельным представлением.

## `/src/i18n`

Каталог `/src/i18n` содержит ресурсы интернационализации, используемые i18next.

Файл `/src/i18n/index.js` должен определить, какую локаль использовать, а затем загрузить соответствующий набор ресурсов i18n.
Ресурсы должны быть сгруппированы по языку и по той части пользовательского интерфейса, для которой они предназначены.

## `/src/mixins`

Каталог `/src/mixins` содержит миксины, используемые в веб-приложении, глобально или локально.
Общие миксины импортируются из репозитория `lowcode-vue`.

## `/src/plugins`

Каталог `/src/plugins` содержит плагины, используемые в веб-приложении.
Общие плагины импортируются из репозитория `lowcode-vue`.

## `/src/store`

Каталог `/src/store` содержит определение хранилища Vuex и логику управления им.
Хранилище следует использовать для хранения данных, которые должны быть доступны в разных компонентах, например модулей Compose и системных пользователей.

## `/src/themes`

Каталог `/src/themes` содержит ресурсы, используемые для стилизации веб-приложения.
Весь код стилизации следует размещать здесь, а не в компонентах.

## `/src/views`

Каталог `/src/views` содержит все доступные представления веб-приложения и их определения маршрутизатора.

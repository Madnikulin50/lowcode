# Веб-приложения

Веб-приложения написаны на [Vue.js](https://vuejs.org/) и предоставляют пользовательский интерфейс для взаимодействия со всей системой.

Основные веб-приложения находятся внутри монорепозитория {GIT*REPO*LINK_PREFIX}[`lowcode`] в каталоге `client/web`.

Взаимодействие между сервером LowCoooode и веб-приложениями осуществляется с помощью REST API и веб-сокетов.

## Настройка среды разработки

### Форкните веб-приложение LowCoooode

!!! note
    Ключевые контрибьюторы могут пропустить эту часть.


1. перейдите в репозиторий {GIT*REPO*LINK_PREFIX}
1. нажмите кнопку btn:[Fork] в правом верхнем углу и следуйте инструкциям на экране.

### Клонируйте репозиторий

.С помощью CLI:
1. откройте CLI
1. перейдите в вашу рабочую папку
1. выполните команду `git clone git@github.com:lowcode/lowcode.git`

!!! tip
    Обратитесь к репозиторию, если хотите использовать альтернативный метод.


### Настройте окружение

.В каталоге вашего веб-приложения:
1. выполните `cp public/config.example.js public/config.js` для *Linux* или в папке `public` выполните `copy config.example.js config.js` для *Windows*
1. откройте файл `config.js` с помощью VIM, Nano или любого другого редактора и измените конфигурацию по своему усмотрению

### Настройте API

.Определите API в файле `public/config.js`, задав:
```js
```
window.LowCoooodeAPI = '$BASE_URL'

Параметр `$BASE_URL` — это адрес вашего сервера LowCoooode.
Если вы запускаете сервер на http://localhost:80, то значение должно быть `http://localhost:80/api`.

### Настройте API аутентификации

Веб-приложения LowCoooode аутентифицируют пользователя с помощью потока OAuth2.

Эту часть можно пропустить, если для аутентификации и обработки используется один и тот же сервер LowCoooode.
Веб-приложение сгенерирует эндпоинты аутентификации на основе параметра `LowCoooodeAPI`.

.Определите API аутентификации в файле `public/config.js`, задав:
```js
```
window.LowCoooodeAuth = '$BASE_URL/auth'

### Убедитесь в наличии зависимостей

!!! caution
    При использовании изменённых версий `lowcode-js` и `lowcode-vue` обязательно свяжите их с помощью `yarn link @lowcode/lowcode-js` и `yarn link @lowcode/lowcode-vue`.


Выполните команду `yarn`, чтобы убедиться, что все пакеты присутствуют и актуальны.

Сведения о поддерживаемых версиях Node.js см. в файле `package.json`.

### Запустите веб-приложение

Выполните команду `yarn serve`, чтобы запустить веб-приложение.
Вы можете использовать необязательный флаг `--port $POST`, чтобы указать порт, на котором оно должно запуститься.

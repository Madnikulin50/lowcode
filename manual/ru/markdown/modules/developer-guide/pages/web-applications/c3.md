# C3

LowCoooode Component Catalogue (C3) — это инструмент для создания UI-компонентов в изолированной среде, упрощающий разработку независимых компонентов.

C3 был вдохновлён Storybook, с главным отличием — «подключением» к компонентам вместо определения историй для описания функциональности.

## Обзор структуры

### `src/dev-env.js`

Файл `src/dev-env.js` определяет всю конфигурацию, требуемую функцией C3; по сути, он определяет изолированное приложение Vue.

Обратитесь к [client/web/admin; /src/dev-env.js](https://github.com/lowcode/lowcode/blob/{PAGE-VERSION}.x/client/web/admin/src/dev-env.js) за примером конфигурации.

<a id="c3-registry"></a>
### `components/C3.js`

Файл `components/C3.js` — это основной реестр, определяющий компоненты, доступные функции C3.

Обратитесь к [client/web/admin; /src/components/C3.js](https://github.com/lowcode/lowcode/blob/{PAGE-VERSION}.x/client/web/admin/src/components/C3.js) за примером конфигурации

### `*.c3.js`

Файл `*.c3.js` определяет конфигурацию C3 для данного компонента.
И файл конфигурации, и файл компонента должны иметь одно и то же имя.

Например, `CSubmitButton.vue` должен определять файл конфигурации `CSubmitButton.c3.js`.

## Добавление новых компонентов

.Чтобы зарегистрировать компонент в C3, вам необходимо:
- определить файл конфигурации `.c3.js`
- определить файл компонента `.vue`
- зарегистрировать компонент в реестре C3

Если всё сделано правильно, результат должен выглядеть примерно как на следующем скриншоте.

.На скриншоте показан пример отображения компонента кнопки конфигурации внутри C3.
![](web-applications/c3-example-submit-button.png)

### Определите файл конфигурации

Файл конфигурации `.c3.js` должен быть назван по имени самого компонента.
Например, компонент `Button.vue` должен определять файл конфигурации `Button.c3.js`.

.Справочник по файлу конфигурации:
```js
```
const props = { <1>
  processing: false,
  success: false,
  disabled: true,
  buttonClass: 'mt-2 pt-1',
  variant: 'outline-primary',
  iconVariant: '',
}

export default {
  name : 'Submit button', <2>
  group : ['Root components'], <3>
  component, <4>
  props,

  controls: [ <5>
    checkbox('Processing', 'processing'),
    checkbox('Success', 'success'),
    checkbox('Disabled', 'disabled'),
    input('Button class', 'buttonClass'),
  ],

  scenarios: [ <6>
    { label: 'Full form',
      props,
    },
    { label: 'Empty form',
      props: {
        ...props,
        disabled: false,
        buttonClass: '',
      },
    },
  ],
}
<1> Объект, содержащий все свойства, которые должны быть переданы в компонент при его отображении.
Дополнительные свойства могут быть переданы через сценарии для модификации по необходимости.
<2> Имя компонента.
<3> Группа позволяет группировать общие или связанные компоненты вместе.
<4> Сам компонент.
<5> Определяет набор элементов управления, которые можно использовать для взаимодействия со свойствами компонентов.
Доступные элементы управления: `generic`, `input`, `textarea`, `checkbox` и `select`.
<6> Сценарии определяют набор предопределённых... сценариев для отображения того, как компонент выглядит в разных состояниях.

### Добавьте запись в реестр C3

Чтобы сделать компонент доступным, вам необходимо зарегистрировать его в [c3-registry,реестре](#c3-registry,реестре).

.Пример добавления компонента `CSubmitButton`:
```js
```
import { default as CSubmitButton } from './CSubmitButton.c3'

export default {

  CSubmitButton,
}

## Изучение интерфейса C3

.На скриншоте показан пример отображения компонента кнопки конфигурации внутри C3.
![](web-applications/c3-example-submit-button.png)

Зарегистрированные компоненты доступны в левой навигации, сгруппированные по своим группам.

При открытии компонент и его элементы управления отображаются в правой части экрана.

Вверху находится компонент.

Внизу слева находятся элементы управления, которые позволяют изменять свойства данного сценария

Внизу справа находятся предопределённые сценарии, описывающие более важные состояния, в которых может находиться компонент.

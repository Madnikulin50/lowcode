## Инфраструктура сборки

Все репозитории LowCoooode используют GitHub workflows и actions для выпуска бинарных файлов сервера, бандлов веб-приложений, Docker-образов и других форматов вывода.

## Версионирование

Поднимите версию NPM-пакетов, следуя стандарту [CalVer](https://calver.org/); например, `2020.9-rc.1`.

Выпущенные версии также должны быть помечены тегами.

.Используйте эту команду Git, чтобы сделать это:
```bash
```
# $V is the version; for example export V=2021.9.0;
git tag $V && git push origin $V;

## Бинарные файлы и бандлы

Все артефакты хранятся на https://releases.lowcode.org/files.
При сборке Docker-образов исходные файлы берутся из хранилища, упомянутого выше.

Docker-образы размещаются на [DockerHub](https://hub.docker.com/u/lowcode).

Неофициально вы можете использовать выпущенные пакеты с Vagrant-окружением https://github.com/{GIT*REPO*GROUP}/{GIT*REPO*PREFIX}-vagrant.

В качестве альтернативы вы можете (собрать и) установить эти пакеты вручную, либо на виртуальной машине, либо на обычном компьютере.

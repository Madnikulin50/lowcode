# Начало работы

## Пример функции

Для более наглядного представления мы используем следующую спецификацию функции:


Пример функции реализует совершенно новую систему мониторинга для всех устройств, подключённых к основной системе; их доступность и потребление памяти.
Функция определяет новый API, новую схему базы данных и современное веб-приложение.

Веб-приложение реализует систему опроса, которая периодически получает информацию о системе, отправляет её через API и сохраняет в базе данных.
Помимо хранения, API также позволяет получать, обновлять и удалять данные.

## Обратите внимание на важные моменты

Укажите **набор пунктов** (разделов), которые **обозначают важные части** системы — то, что вы хотите, чтобы **читатели запомнили**.

Например:

```adoc
```
- безопасность
- фронтенд
- бэкенд
- репозиторий

## Раскройте основные вещи

**Раскройте** основные разделы.
Разбейте их на **основные компоненты**, описывающие раздел.

Например:

```adoc
```
- безопасность
** доступные разрешения
** сфера действия каждого разрешения
** рекомендации

- фронтенд
** используемые важные библиотеки
** совместимость с браузерами
** используемые алгоритмы
** взаимодействие с бэкендом

- бэкенд
** контроль доступа
** используемые алгоритмы
** ограничения, такие как троттлинг

- репозиторий
** таблицы, поля и их типы

## Итерируйте по своим пунктам

**Итерируйте по своим документам** и постепенно **расширяйте и рефакторите** своё содержимое.
Попробуйте переписать один и тот же абзац **несколько раз**, чтобы понять, что подходит лучше всего.
Добавьте немного **блоков примечаний** и **форматирования текста**.

Например:

```adoc
```
# Monitor

Эта функция реализует систему, которая отслеживает клиентов, подключённых к основной системе Monitor LowCoooode.

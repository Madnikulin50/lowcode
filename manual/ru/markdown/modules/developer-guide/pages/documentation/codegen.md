# Генерация кода

Для генерации документации вам нужны две команды (в какой-то момент мы прекратим поддержку устаревшей):

```bash
DOCS_DIR=../path/to/docs/repo make codegen
```

```bash
make codegen-legacy && ~/go/bin/lowcode-codegen -d ../path/to/docs/repo
```

!!! note
    Вторая команда неоптимальна, но на данный момент я не совсем уверен, как сделать это одним махом (как передать флаг `-d` вызываемой команде).
